## 考えていたこと

10月から参画だったが12月までの仮採用で, 1月以降も継続かどうかは3か月の働きぶり次第だった
まず考えたこと
- 1月以降も継続してほしいと思えるような人になってもらいたい
    継続したいと思うには何が必要か　→　お金を払う分の仕事はしてもらいたい

まずは仕事ができる人になってもらいたい
では仕事ができる人とはどのような人か
- タスクを自分で取る　→　やるべきことがわかる　→　自分で作業を進められる, わからないところは聞く　→　レビューしてもらう　→　次のタスクを取る　→　…

基本的に「どうすれば価値が高くなるか」「今価値が高い行動は何か」を考えている
