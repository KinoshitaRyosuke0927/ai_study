関数一覧
1 create_new_task(task_name: str, user_id: int) → TaskDetailResponse ▼
処理目的

新たなタスクを作成し、その内容をデータベースへ登録してレスポンスとして返す。

出力
  • TaskDetailResponse：作成タスクの詳細情報と検証結果メッセージ。
入力
  • task_name：タスク名称
  • user_id：タスクを作成したユーザのID
アルゴリズム
  1. 1common_validate.length_validation で名称の長さ（1〜255文字）を検証。
  2. 2エラーがあれば TaskDetailResponse にエラーを格納して返却。
  3. 3DBへ insert_task(task_name, user_id) を実行し、新規レコードを作成。
  4. 4作成結果をDataFrameから辞書に変換。
  5. 5正常完了時はメッセージ空でレスポンス返却。
2 get_task_info(task_id: int) → TaskDetailResponse ▼
処理目的

指定タスクの状態を取得し、タスク詳細および表示用オブジェクト情報を返す。

入力
  • task_id：照会対象タスクのID
アルゴリズム
  1. 1DBからタスク情報取得 (select_task_by_task_id)。
  2. 2該当なし→「msg-E-0005」メッセージを返す。
  3. 3タスク状態に応じて match 文で処理分岐：DOING / RERUN / DONE
  4. 4タスク詳細・メッセージ・表示情報をまとめて返却。
3 get_task_detail(task_id: int) → TaskDetailResponse ▼
処理目的

翻訳済みタスクの変換結果ファイルを取得して返す。

アルゴリズム
  1. 1select_task_by_task_id でタスク情報取得。
  2. 2該当なし / DONE 以外の場合は「msg-E-0005」返却。
  3. 3generate_display_info で結果ファイルを取得。
  4. 4タスク詳細・ファイル表示情報をレスポンスにまとめ返却。
4 update_task_name(task_id: int, task_name: str) → TaskDetailResponse ▼
処理目的

既存タスクの名称を更新する。

アルゴリズム
  1. 1名称長さを common_validate.length_validation で確認。
  2. 2エラー存在時は即返却。
  3. 3update_task_name を実行し結果取得。
  4. 4該当レコードなしなら「msg-E-0003」返却。
  5. 5正常更新結果を辞書変換しレスポンス返却。
5 delete_task(task_id: int) → TaskDetailResponse ▼
処理目的

指定タスクおよび関連データ（アップロード・結果ファイル）を削除する。

アルゴリズム
  1. 1select_task_by_task_id で存在確認。なし→「msg-E-0005」返却。
  2. 2タスク状態確認。実行中(DOING)→「msg-E-0006」返却。
  3. 3delete_task により削除実行。失敗→「msg-E-0004」返却。
  4. 4関連オブジェクト・結果ファイルも削除。Azureフォルダ削除。
  5. 5削除済タスク名を挿入した「msg-I-0001」メッセージ生成。
6 translate_files(target_file_list, metadata_list, task_id, user_id, background_tasks) → TaskDetailResponse ▼
処理目的

アップロードファイルをAI変換処理にかけ、変換をバックグラウンドで実行する。

アルゴリズム
  1. 1ファイル型オブジェクトのみ抽出し検証 (filter_data)。有効ファイルなし→「msg-E-0009」返却。
  2. 2DBからタスク情報取得・存在確認。翻訳中/完了タスクなら「msg-E-0007」返却。
  3. 3アップロードオブジェクトをDB登録 (insert_upload_objects)。パスとIDの辞書を作成。
  4. 4background_tasks.add_task(async_translate_file, …) で非同期変換処理登録。
  5. 5タスク状態を DOING に更新。「msg-I-0002」を追加してレスポンス返却。
7 async_translate_file(target_file_df, upload_file_dict, task_id, user_id) ▼
処理目的

バックグラウンドでAzure AIを使用してコード変換し、結果をDBとファイル共有に登録する。

アルゴリズム
  1. 1各ファイルごとに azure_ai_operation_service.translate_code でコード変換。
  2. 2変換結果をAzureファイル共有にアップロード。
  3. 3変換結果をDB登録 (insert_result_files)。タスク状態を DONE に更新。
  4. 4エラー発生時：関連DBデータ・共有ファイル削除。タスク状態を RERUN に更新。
8 generate_display_info(task_id: int, task_state: int) → list[dict] ▼
処理目的

指定タスクに紐づく表示オブジェクト情報を生成。タスク状態に応じて変換結果を取得または空結果を返す。

アルゴリズム
  1. 1DOING：アップロードオブジェクト取得。result_text を空で追加し辞書配列に変換して返却。
  2. 2DONE：各ファイルの変換結果をAzureファイル共有から取得して result_text に格納。
  3. 3DataFrameを辞書配列に変換して返却。
