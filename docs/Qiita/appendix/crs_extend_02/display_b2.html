目処理目的
新たなタスクを作成し、その内容をデータベースへ登録してレスポンスとして返す。
入入力パラメータ
引数名型説明
task_namestrタスク名称
user_idintタスクを作成したユーザのID
出出力
型説明
TaskDetailResponse作成したタスクの詳細情報と検証結果メッセージ。
手アルゴリズム
  1. 1common_validate.length_validation で名称の長さ（1〜255文字）を検証。
  2. 2エラーがあれば TaskDetailResponse にエラーを格納して返却。
  3. 3DBへ insert_task(task_name, user_id) を実行し、新規レコードを作成。
  4. 4作成結果をDataFrameから辞書に変換。
  5. 5正常完了時はメッセージ空でレスポンス返却。
目処理目的
指定タスクの状態を取得し、タスク詳細および表示用オブジェクト情報を返す。
入入力パラメータ
引数名型説明
task_idint照会対象タスクのID
出出力
型説明
TaskDetailResponseタスクの状態・メッセージ・表示用オブジェクト情報。
手アルゴリズム
  1. 1DBからタスク情報取得 (select_task_by_task_id)。
  2. 2該当なし → 「msg-E-0005」メッセージを返す。
  3. 3タスク状態に応じて match 文で処理分岐：DOING / RERUN / DONE
  4. 4タスク詳細・メッセージ・表示情報をまとめて返却。
目処理目的
翻訳済みタスクの変換結果ファイルを取得して返す。
入入力パラメータ
引数名型説明
task_idint対象タスクID
出出力
型説明
TaskDetailResponse翻訳結果情報。
手アルゴリズム
  1. 1select_task_by_task_id でタスク情報取得。
  2. 2該当なし / DONE 以外の場合は「msg-E-0005」返却。
  3. 3generate_display_info で結果ファイルを取得。
  4. 4タスク詳細・ファイル表示情報をレスポンスにまとめ返却。
目処理目的
既存タスクの名称を更新する。
入入力パラメータ
引数名型説明
task_idint更新対象タスクID
task_namestr新しいタスク名称
出出力
型説明
TaskDetailResponse更新後のタスク情報またはエラーメッセージ。
手アルゴリズム
  1. 1名称長さを common_validate.length_validation で確認（1〜255文字）。
  2. 2エラー存在時は即返却。
  3. 3update_task_name を実行し結果取得。
  4. 4該当レコードなしなら「msg-E-0003」返却。
  5. 5正常更新結果を辞書変換しレスポンス返却。
目処理目的
指定タスクおよび関連データ（アップロード・結果ファイル）を削除する。
入入力パラメータ
引数名型説明
task_idint削除対象タスクID
出出力
型説明
TaskDetailResponse削除結果のメッセージと削除したタスク情報。
手アルゴリズム
  1. 1select_task_by_task_id で存在確認。なし → 「msg-E-0005」返却。
  2. 2タスク状態確認。実行中 (DOING) → 「msg-E-0006」返却。
  3. 3delete_task により削除実行。失敗 → 「msg-E-0004」返却。
  4. 4関連オブジェクト・結果ファイルも削除 (delete_upload_object, delete_result_file)。
  5. 5Azureファイル共有のフォルダ削除 (delete_task_directory)。
  6. 6削除済タスク名を挿入した「msg-I-0001」メッセージを生成して返却。
目処理目的
アップロードファイルをAI変換処理にかけ、変換をバックグラウンドで実行する。
入入力パラメータ
引数名型説明
target_file_listlist[File]アップロードされたファイルのリスト。
metadata_listlist[dict]各ファイルのメタデータ。
task_idint対象タスクID。
user_idint対象ユーザID。
background_tasksBackgroundTasks非同期実行制御用FastAPIオブジェクト。
出出力
型説明
TaskDetailResponse処理開始時のステータスとメッセージ。
手アルゴリズム
  1. 1ファイル型オブジェクトのみ抽出し検証 (filter_data)。有効ファイルなし → 「msg-E-0009」返却。
  2. 2DBからタスク情報取得・存在確認。翻訳中または完了タスクなら「msg-E-0007」返却。
  3. 3アップロードオブジェクトをDB登録 (insert_upload_objects)。ファイルパスとIDの辞書を作成。
  4. 4各ファイル内容を upload_file_dict に格納（キー: オブジェクトID）。
  5. 5background_tasks.add_task(async_translate_file, …) で非同期変換処理を登録。
  6. 6タスク状態を DOING に更新。「msg-I-0002」を追加してレスポンス返却。
  7. 7例外発生時はログ出力と「msg-E-0007」返却。
目処理目的
バックグラウンドでAzure AIを使用してコード変換し、結果をDBとAzureファイル共有に登録する。
入入力パラメータ
引数名型説明
target_file_dfpd.DataFrameアップロード対象ファイルのDataFrame。
upload_file_dictdict[int, str]ファイル内容辞書。キー: object_id。
task_idint対象タスクID。
user_idint対象ユーザID。
出出力
戻り値はありません。結果はDBおよびAzureファイル共有に直接登録されます。
手アルゴリズム
  1. 1各ファイルごとに azure_ai_operation_service.translate_code でコード変換を実施。
  2. 2変換結果ファイル辞書・結果データ辞書を生成しリストへ追加。
  3. 3変換結果をAzureファイル共有にアップロード。
  4. 4変換結果をDB登録 (insert_result_files)。タスク状態を DONE に更新。
  5. 5エラー発生時：エラーログ出力。関連DBデータ・共有ファイルを削除。タスク状態を RERUN に更新。
目処理目的
指定タスクに紐づく表示オブジェクト情報を生成する。タスク状態に応じて変換結果を取得するか、空結果を返す。
入入力パラメータ
引数名型説明
task_idint対象タスクのID。
task_stateintタスク状態値。分岐処理に使用。
出出力
型説明
list[dict]表示用オブジェクト情報の配列。
手アルゴリズム
  1. 1タスク状態に応じて分岐。
  2. 2DOING：アップロードオブジェクト取得 (select_upload_object_by_task_id)。result_text を空で追加し辞書配列に変換して返却。
  3. 3DONE：各ファイルの変換結果をAzureファイル共有から取得して result_text に格納。
  4. 4DataFrameを辞書配列に変換して返却。
