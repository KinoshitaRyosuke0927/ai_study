def create_new_task(task_name: str, user_id: int) → TaskDetailResponse

新たなタスクを作成し、その内容をデータベースへ登録してレスポンスとして返す。

入力
出力
アルゴリズム
  • task_namestr タスク名称
  • user_idint タスクを作成したユーザのID
  • TaskDetailResponse作成したタスクの詳細情報と検証結果メッセージ。
  1. 1common_validate.length_validation で名称の長さ（1〜255文字）を検証。
  2. 2エラーがあれば TaskDetailResponse にエラーを格納して返却。
  3. 3DBへ insert_task(task_name, user_id) を実行し新規レコードを作成。
  4. 4作成結果をDataFrameから辞書に変換。正常完了時はメッセージ空でレスポンス返却。

def get_task_info(task_id: int) → TaskDetailResponse

指定タスクの状態を取得し、タスク詳細および表示用オブジェクト情報を返す。

入力
出力
アルゴリズム
  • task_idint 照会対象タスクのID
  • TaskDetailResponseタスクの状態およびメッセージ・表示情報。
  1. 1DBからタスク情報取得 (select_task_by_task_id)。
  2. 2該当なし→「msg-E-0005」メッセージを返す。
  3. 3タスク状態に応じて match 文で処理分岐：DOING / RERUN / DONE
  4. 4タスク詳細・メッセージ・表示情報をまとめて返却。

def delete_task(task_id: int) → TaskDetailResponse

指定タスクおよび関連データ（アップロード・結果ファイル）を削除する。

入力
出力
アルゴリズム
  • task_idint 削除対象タスクID
  • TaskDetailResponse削除結果のメッセージと削除したタスク情報。
  1. 1select_task_by_task_id で存在確認。なし→「msg-E-0005」返却。
  2. 2実行中(DOING)→「msg-E-0006」返却。
  3. 3delete_task により削除実行。失敗→「msg-E-0004」返却。
  4. 4関連オブジェクト・結果ファイルも削除。Azureフォルダ削除。
  5. 5削除済タスク名を挿入した「msg-I-0001」メッセージ生成し返却。

def translate_files(target_file_list, metadata_list, task_id, user_id, background_tasks) → TaskDetailResponse

アップロードファイルをAI変換処理にかけ、変換をバックグラウンドで実行する。

入力
出力
アルゴリズム
  • target_file_listアップロードされたファイルのリスト。
  • metadata_listファイルメタデータ。
  • task_id, user_id対象タスク・ユーザ識別情報。
  • background_tasks非同期実行制御用FastAPIオブジェクト。
  • TaskDetailResponse処理開始時のステータスとメッセージ。
  1. 1ファイル型オブジェクトのみ抽出 (filter_data)。有効ファイルなし→「msg-E-0009」返却。
  2. 2DBからタスク情報取得・存在確認。翻訳中/完了タスクなら「msg-E-0007」返却。
  3. 3アップロードオブジェクトをDB登録 (insert_upload_objects)。
  4. 4background_tasks.add_task(async_translate_file) で非同期変換処理登録。
  5. 5タスク状態を DOING に更新。「msg-I-0002」を追加してレスポンス返却。

def async_translate_file(target_file_df, upload_file_dict, task_id, user_id)

バックグラウンドでAzure AIを使用してコード変換し、結果をDBとファイル共有に登録する。

入力
出力
アルゴリズム
  • target_file_dfアップロード対象ファイルのDataFrame。
  • upload_file_dictファイル内容辞書 {object_id: file_content}。
  • task_id, user_idタスクおよびユーザ識別情報。
  • なし直接DBとAzureに登録。戻り値なし。
  1. 1各ファイルごとに azure_ai_operation_service.translate_code でコード変換。
  2. 2変換結果をAzureファイル共有にアップロード。
  3. 3変換結果をDB登録 (insert_result_files)。タスク状態を DONE に更新。
  4. 4エラー発生時：関連DBデータ・共有ファイル削除。タスク状態を RERUN に更新。

def generate_display_info(task_id: int, task_state: int) → list[dict]

指定タスクに紐づく表示オブジェクト情報を生成。タスク状態に応じて変換結果を取得または空結果を返す。

入力
出力
アルゴリズム
  • task_idint 対象タスクのID。
  • task_stateint タスク状態値。
  • list[dict]表示用オブジェクト情報の配列。
  1. 1DOING：アップロードオブジェクト取得。result_text を空で追加。
  2. 2DONE：各ファイルの変換結果をAzureファイル共有から取得して result_text に格納。
  3. 3DataFrameを辞書配列に変換して返却。
