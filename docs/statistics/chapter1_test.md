# 解答・解説

## 解答一覧

1: A　2: C　3: D　4: B　5: C　6: B　7: A　8: B
9: D　10: C　11: C　12: B　13: B　14: C　15: D

---

## 主要問題の解説

### 問題1
昇順：5, 8, 10, **14**, 18, 22, 25（n=7、4番目） → **A: 14**

### 問題3
右歪み分布では、右側の外れ値が平均を引き上げる → 平均 > 中央値 > 最頻値
**→ D**

### 問題5
平均 = 6、偏差の二乗 = 16+4+0+4+16 = 40
$\sigma^2 = 40/5 = 8$
**→ C**

### 問題7
不偏分散の分母は n−1 = 10−1 = **9**
**→ A**

### 問題8
n=8のデータ、Q1 = 下半分（4,8,12,16）の中央値 = (8+12)/2 = **10**
**→ B**

### 問題14
各データセットの分散：
- A: 0
- B: 平均10、偏差の二乗：1+0+1+0 = 2 → σ²=0.5
- C: 平均10、偏差の二乗：25+4+4+25 = 58 → σ²=14.5
- D: 平均10、偏差の二乗：4+1+1+4 = 10 → σ²=2.5
最大は **C**

### 問題15
IQR = 35−15 = 20
上限 = 35 + 1.5×20 = 35+30 = **65 → D**
