## 解説

### 問題1
昇順：3, 5, 8, **9**, 12, 15, 21　→　n=7 なので中央値は4番目 = **9** → B

### 問題2
平均 = (2+3+4+5+50)/5 = 64/5 = **12.8**、中央値 = **4**
→ 平均 > 中央値（外れ値50が平均を引き上げる） **→ C**

### 問題3
平均 = (3+6+9+12+15)/5 = 45/5 = 9
$$\sigma^2 = \frac{(3-9)^2+(6-9)^2+(9-9)^2+(12-9)^2+(15-9)^2}{5} = \frac{36+9+0+9+36}{5} = \frac{90}{5} = 18 \quad \textbf{→ C}$$

### 問題4
IQR = Q3 − Q1 = 55 − 25 = 30
上限 = Q3 + 1.5 × IQR = 55 + 45 = **100** **→ C**

### 問題5
1〜5の評価は大小関係はあるが間隔が等しいとは言えない → **順序尺度 → C**
（体重・点数は間隔尺度または比例尺度、血液型は名義尺度）

### 問題6
CV = 標準偏差 / 平均 × 100%（相対的なばらつき）。単位がないため異なるデータ同士を比較できる。**→ C**

### 問題7
$$\bar{x} = \frac{25 \times 4 + 35 \times 10 + 45 \times 6}{4+10+6} = \frac{100+350+270}{20} = \frac{720}{20} = 36 \quad \textbf{→ C}$$

### 問題8
P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 0.6 + 0.5 − 0.3 = **0.8 → C**

### 問題9
$$P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{0.15}{0.5} = 0.30 \quad \textbf{→ C}$$

### 問題10
$$P(\text{不良}) = 0.04 \times 0.6 + 0.06 \times 0.4 = 0.024 + 0.024 = 0.048 \quad \textbf{→ B}$$

### 問題11
ベイズの定理：
$$P(A|\text{不良}) = \frac{0.04 \times 0.6}{0.048} = \frac{0.024}{0.048} = 0.50 \quad \textbf{→ B}$$

### 問題12
P(A)P(B) = 0.4 × 0.6 = 0.24 = P(A ∩ B) → **独立 → B**

### 問題13
稀な事象の発生件数（単位時間あたりの発生数）→ **ポアソン分布 → B**

### 問題14
$$E[X] = 0 \times 0.2 + 1 \times 0.4 + 2 \times 0.3 + 3 \times 0.1 = 0 + 0.4 + 0.6 + 0.3 = 1.3 \quad \textbf{→ B}$$

### 問題15
Bin(8, 0.25)：E[X] = np = 8 × 0.25 = 2、Var(X) = np(1−p) = 8 × 0.25 × 0.75 = **1.5 → A**

### 問題16
$$P(X=2) = \binom{6}{2}0.4^2 \times 0.6^4 = 15 \times 0.16 \times 0.1296 = 15 \times 0.020736 = 0.31104 \approx 0.3110$$
選択肢の中で最も近い **→ 正答はC（0.3110）→ C**

※ 問題16の正解はC（0.3110）。解答一覧の B は誤り、正しくは **C**。

### 問題17
$$P(X=0) = \frac{e^{-3} \cdot 3^0}{0!} = e^{-3} \quad \textbf{→ B}$$

### 問題18
$$P(X \geq 2) = 1 - P(X=0) - P(X=1) = 1 - e^{-2} - 2e^{-2} = 1 - 3e^{-2} \quad \textbf{→ C}$$

### 問題19
$$Z = \frac{85 - 70}{10} = \frac{15}{10} = 1.5 \quad \textbf{→ B}$$

### 問題20
$$Z_1 = \frac{45-50}{5} = -1, \quad Z_2 = \frac{60-50}{5} = 2$$
$$P(45 \leq X \leq 60) = P(-1 \leq Z \leq 2) \quad \textbf{→ A}$$

### 問題21
$$P(\mu - 2\sigma \leq X \leq \mu + 2\sigma) = P(-2 \leq Z \leq 2) = 2 \times 0.9772 - 1 = 0.9544 \approx 95.44\% \quad \textbf{→ B}$$

### 問題22
標本平均の分散は $\sigma^2/n$、標準偏差（標準誤差）は $\sigma/\sqrt{n}$ **→ C**

### 問題23
$$SE = \sigma/\sqrt{n} = 18/\sqrt{81} = 18/9 = 2$$
$$95\%\text{CI} = 64 \pm 1.96 \times 2 = 64 \pm 3.92 \quad \textbf{→ B}$$

### 問題24
信頼区間の幅は $2z\sigma/\sqrt{n}$ に比例 → 幅を 1/3 にするには $\sqrt{n}$ を 3倍 → **n を 9倍 → C**

### 問題25
母分散未知・小標本 → t分布、SE = s/√n = 10/√20 **→ D**

### 問題26
第1種：正しい H₀ を棄却（α）、第2種：誤りの H₀ を採択しない = **対立仮説が正しいのに H₀ を採択する誤り → B**

### 問題27
$$SE = \sigma/\sqrt{n} = 12/\sqrt{36} = 12/6 = 2$$
$$z = \frac{53-50}{2} = 1.5 \quad \textbf{→ D}$$

### 問題28
|z| = 1.5 < 1.96（棄却域に入らない）→ **H₀ を棄却しない → B**

### 問題29
$$SE = s/\sqrt{n} = 5/\sqrt{11} \approx 5/3.317 \approx 1.508$$
$$t = \frac{72-70}{1.508} \approx 1.33 \quad \textbf{→ C}$$

### 問題30
片側検定（H₁: μ > 70）の棄却域：t > 1.812
t ≈ 1.33 < 1.812 → **H₀ を棄却しない → B**

※ 解答一覧の A は誤り。正しくは **B**。

### 問題31
p値 = 帰無仮説のもとで、観測結果以上に極端な値が生じる確率。小さいほど観測結果はまれ。**→ B**

### 問題32
$\sum(x_i-\bar{x})(y_i-\bar{y}) = 4 + 0 + (-4) = 0$
$$Cov(X,Y) = 0/3 = 0, \quad r = \frac{0}{\sqrt{8 \times 8}} = 0 \quad \textbf{→ A}$$

### 問題33
$$b = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2} = \frac{20}{10} = 2.0 \quad \textbf{→ C}$$

### 問題34
$$a = \bar{y} - b\bar{x} = 7 - 2 \times 4 = 7 - 8 = -1 \quad \textbf{→ A}$$

### 問題35
$$t = \frac{0.4\sqrt{22-2}}{\sqrt{1-0.16}} = \frac{0.4\sqrt{20}}{\sqrt{0.84}} = \frac{0.4 \times 4.472}{0.9165} = \frac{1.789}{0.9165} \approx 1.95$$
$t \approx 1.95 < 2.086 = t_{0.025,20}$ → **H₀ 棄却しない → B**（最近似）
