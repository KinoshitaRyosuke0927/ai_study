# 第5章 相関・回帰分析 ― 追加演習（相関係数の検定・計算特化）

本資料は、第5章「相関・回帰分析」のうち、
**相関係数の有意性検定を数値で解くこと**に特化した演習です。

t分布表が別途与えられている前提で解きなさい。

---

## 相関係数の検定の基本

標本サイズ n、相関係数 r が与えられたとき、
母相関係数 ρ = 0 を検定する場合の検定統計量は

\[
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}}
\]

で与えられ、
**自由度 n−2 の t分布**に従う。

---

## 解くときの標準手順

1. 帰無仮説 H₀ : ρ = 0 を設定  
2. 対立仮説（≠0, >0, <0）を確認  
3. 上式で t を計算  
4. 自由度 n−2 の t表から臨界値を取得  
5. |t| と臨界値を比較して結論を出す  

---

## 解答・計算の要点

### 問題1
