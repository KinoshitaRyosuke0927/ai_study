## 主要問題の解説

### 問題4
$$SE = \sigma/\sqrt{n} = 15/\sqrt{100} = 15/10 = 1.5$$
$$\text{95\%CI} = 120 \pm 1.96 \times 1.5 = 120 \pm 2.94 \quad \textbf{→ B}$$

### 問題5
信頼区間の幅は $2 \times z \times \sigma/\sqrt{n}$ に比例。幅を半分にするには $\sqrt{n}$ を2倍 → $n$ を **4倍**（100×4=**400**）→ D

### 問題6
母分散未知・小標本なので **t分布**を使用。自由度 = n−1 = 24。
$$SE = s/\sqrt{n} = 10/\sqrt{25} = 10/5 = 2$$
$$\text{95\%CI} = 50 \pm 2.064 \times 2 \quad \textbf{→ B}$$

### 問題8
$$SE = \sqrt{\hat{p}(1-\hat{p})/n} = \sqrt{0.6 \times 0.4/400} = \sqrt{0.0006} \approx 0.0245$$
$$0.6 \pm 1.96 \times 0.0245 \approx 0.6 \pm 0.048 \quad \textbf{→ B}$$

### 問題10
$$z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{53-50}{10/\sqrt{25}} = \frac{3}{10/5} = \frac{3}{2} = 1.5 \quad \textbf{→ C}$$

### 問題11
$|z| = 1.5 < 1.96$（棄却域に入らない）→ **H₀を棄却しない → A**

### 問題12
$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} = \frac{72-68}{8/\sqrt{16}} = \frac{4}{8/4} = \frac{4}{2} = 2.0 \quad \textbf{→ C}$$

### 問題13
片側検定（H₁: μ>68）の棄却域：$t > t_{0.05,15} = 1.753$
$t = 2.0 > 1.753$ → **H₀を棄却 → B**

### 問題16
$$z = \frac{\hat{p} - p_0}{SE} = \frac{0.60 - 0.50}{0.05} = \frac{0.10}{0.05} = 2.0 \quad \textbf{→ B}$$
$|z| = 2.0 > 1.96$ → 有意水準5%で H₀を棄却（表の出方に偏りあり）
