# 第2章 確率 ― 解説編

本章では、統計検定2級で扱われる**確率の基礎概念と計算方法**を学びます。
確率は以降の「確率分布」「推測統計」の前提となるため、定義と考え方を正確に理解することが重要です。

> 本章の重点：式を暗記するのではなく、「事象の関係を整理してから式を使う」習慣をつける。

---

## 2-1 確率の基本概念

### 試行・事象・標本空間

| 用語 | 定義 | 例（サイコロ1回） |
|------|------|-----------------|
| **試行** | 結果が偶然に左右される実験や行為 | サイコロを1回投げる |
| **標本空間 Ω** | 起こりうるすべての結果の集合 | {1, 2, 3, 4, 5, 6} |
| **事象 A** | 試行の結果として起こる出来事（標本空間の部分集合） | 偶数の目が出る = {2, 4, 6} |
| **全事象** | 必ず起こる事象（標本空間全体） | {1, 2, 3, 4, 5, 6} |
| **空事象** | 決して起こらない事象 | {7}（サイコロで7は出ない） |

---

## 2-2 確率の定義

### 古典的確率（ラプラスの確率）
すべての結果が**同様に起こりやすい**とき：

$$P(A) = \frac{|A|}{|\Omega|} = \frac{\text{事象Aが起こる場合の数}}{\text{全体の場合の数}}$$

**計算例**
サイコロで偶数が出る確率：$P(\text{偶数}) = \frac{3}{6} = \frac{1}{2}$

### 頻度論的確率（相対度数）
同じ試行をN回繰り返したとき、事象Aがk回起こったとすると：

$$P(A) \approx \frac{k}{N} \quad (N \to \infty)$$

---

## 2-3 確率の性質

**公理（コルモゴロフの確率の公理）**

1. $0 \leq P(A) \leq 1$（確率は0以上1以下）
2. $P(\Omega) = 1$（全事象の確率は1）
3. 排反事象 $A_1, A_2, \ldots$ に対して：$P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots$

**余事象の確率**

$$P(A^c) = 1 - P(A)$$

> 「少なくとも〜」「〜でない」の確率は余事象を使うと計算が楽になる。

**計算例**
サイコロで1が出ない確率：$P(\text{1以外}) = 1 - \frac{1}{6} = \frac{5}{6}$

---

## 2-4 場合の数（組み合わせ・順列）

確率計算では「場合の数」を数えることが基本になる。

### 順列（Permutation）

n個のものからr個を**順番を考慮して**並べる方法の数：

$$_nP_r = \frac{n!}{(n-r)!} = n \times (n-1) \times \cdots \times (n-r+1)$$

**計算例**
5人の中から3人を選んで1位・2位・3位を決める：
$$_5P_3 = 5 \times 4 \times 3 = 60$$

### 組み合わせ（Combination）

n個のものからr個を**順番を考慮せずに**選ぶ方法の数：

$$\binom{n}{r} = {}_nC_r = \frac{n!}{r!(n-r)!}$$

**計算例**
10人の中から3人の委員を選ぶ：
$$\binom{10}{3} = \frac{10!}{3! \cdot 7!} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

### よく使う値
$$\binom{n}{0} = 1, \quad \binom{n}{1} = n, \quad \binom{n}{n} = 1, \quad \binom{n}{r} = \binom{n}{n-r}$$

## 2-5 和事象・積事象と加法定理

### ベン図での整理

```
     Ω（標本空間）
  ┌─────────────────┐
  │  ┌───┐ ┌───┐  │
  │  │ A │∩│ B │  │
  │  └───┘ └───┘  │
  └─────────────────┘
```

| 記号 | 名称 | 意味 |
|------|------|------|
| $A \cup B$ | 和事象 | AまたはBが起こる |
| $A \cap B$ | 積事象 | AかつBが起こる |
| $A^c$ | 余事象 | Aが起こらない |

### 加法定理（一般の場合）

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

**なぜ引くのか**：$A \cap B$の部分がP(A)とP(B)の両方に含まれるため、1回分を引く。

### 排反事象の場合

AとBが排反（$A \cap B = \emptyset$）のとき：

$$P(A \cup B) = P(A) + P(B)$$

**計算例**
P(A)=0.4、P(B)=0.5、P(A∩B)=0.2 のとき：
$$P(A \cup B) = 0.4 + 0.5 - 0.2 = 0.7$$

**陥りやすい間違い**
- 「排反」と「独立」を混同する。排反 = 同時に起こらない。独立 = 一方の結果が他方に影響しない。
- 排反な2事象は（確率が0でない限り）独立にはなれない。

---

## 2-6 条件付き確率

事象Bが起こったという条件のもとで、事象Aが起こる確率：

$$P(A|B) = \frac{P(A \cap B)}{P(B)} \quad (P(B) > 0)$$

**直感的な理解**：Bが起こったことがわかった後、Aが起こる確率 = 「BとAが同時に起きた割合」÷「Bが起きた割合」

**計算例**
赤玉3個・白玉2個の袋から1個取り出し（戻さず）もう1個取り出す。
- 1枚目が赤の確率：$P(R_1) = 3/5$
- 1枚目が赤だったとき2枚目も赤の確率：$P(R_2|R_1) = 2/4 = 1/2$
- 両方赤の確率：$P(R_1 \cap R_2) = P(R_1) \times P(R_2|R_1) = \frac{3}{5} \times \frac{1}{2} = \frac{3}{10}$

---

## 2-7 乗法定理

### 一般の場合

$$P(A \cap B) = P(B) \cdot P(A|B) = P(A) \cdot P(B|A)$$

### 独立事象の場合

$$P(A \cap B) = P(A) \cdot P(B)$$

---

## 2-8 独立事象

**定義**：AとBが独立 ⟺ $P(A \cap B) = P(A)P(B)$

これは「Bが起きたことを知っても、Aの確率が変わらない」ことと同値：
$$P(A|B) = P(A), \quad P(B|A) = P(B)$$

**計算例**
コインを2回投げる。
- A = 1回目が表、$P(A) = 1/2$
- B = 2回目が表、$P(B) = 1/2$
- $P(A \cap B) = 1/4 = P(A) \times P(B)$ → 独立

**排反と独立の違い**

| | 定義 | $P(A \cap B)$ |
|--|------|--------------|
| **排反** | 同時に起こりえない | $P(A \cap B) = 0$ |
| **独立** | 一方が他方に影響しない | $P(A \cap B) = P(A)P(B)$ |

---

## 2-9 全確率の公式

標本空間 Ω が**互いに排反な事象** $B_1, B_2, \ldots, B_k$ に分割されているとき（$B_i \cap B_j = \emptyset$, $\bigcup B_i = \Omega$）：

$$P(A) = \sum_{i=1}^{k} P(A|B_i) P(B_i) = P(A|B_1)P(B_1) + P(A|B_2)P(B_2) + \cdots$$

**直感**：Aが起こるには「$B_1$を経由して起こる」「$B_2$を経由して起こる」……のいずれか → それぞれを足す。

**計算例**
工場A（生産量70%、不良品率2%）と工場B（生産量30%、不良品率5%）から1個選ぶ。
$$P(\text{不良品}) = P(\text{不良}|A) \cdot P(A) + P(\text{不良}|B) \cdot P(B)$$
$$= 0.02 \times 0.7 + 0.05 \times 0.3 = 0.014 + 0.015 = 0.029$$

---

## 2-10 ベイズの定理

条件付き確率を使って、**原因の確率を結果から逆算**する定理。

$$P(B_i|A) = \frac{P(A|B_i)P(B_i)}{P(A)} = \frac{P(A|B_i)P(B_i)}{\sum_j P(A|B_j)P(B_j)}$$

| 用語 | 意味 |
|------|------|
| **事前確率** $P(B_i)$ | 情報を得る前の確率 |
| **尤度** $P(A\|B_i)$ | 原因$B_i$のもとで結果Aが起こる確率 |
| **事後確率** $P(B_i\|A)$ | 結果Aを得た後の確率（更新後） |

**具体例（病気検査）**：
- 疾患の有病率：$P(D) = 0.01$（1%）
- 検査の感度：$P(+|D) = 0.99$（病気なら99%陽性）
- 偽陽性率：$P(+|D^c) = 0.05$（病気でなくても5%陽性）

検査が陽性だったとき、実際に病気の確率 $P(D|+)$ は？

$$P(+) = P(+|D)P(D) + P(+|D^c)P(D^c) = 0.99 \times 0.01 + 0.05 \times 0.99 = 0.0099 + 0.0495 = 0.0594$$

$$P(D|+) = \frac{P(+|D)P(D)}{P(+)} = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} \approx 0.167$$

有病率が低い（1%）と、検査陽性でも実際に病気の確率は約17%しかない（偽陽性問題）。

**陥りやすい間違い**
- $P(A|B)$ と $P(B|A)$ を混同する（これをBase rate neglect という）
- 分母の $P(A)$ を全確率の公式で正しく計算しないと答えが合わない
