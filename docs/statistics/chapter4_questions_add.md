# 第4章 推測統計 ― 追加演習（Z表・t表使用／計算特化）

本資料は、第4章「推測統計」について、  
**正規分布表（Z表）・t分布表が与えられている前提**で、  
計算手順に重点を置いた演習問題集です。

> 目的：  
> - 分布表から臨界値を正しく読む  
> - 区間推定・仮説検定の計算を機械的にミスなく行う  
> - 「zかtか」で迷わなくなる  

---

## 演習の基本手順（共通）

### 区間推定
1. 母分散が **既知か未知か** を確認  
2. 使用する分布（正規 or t）を決定  
3. 分布表から臨界値を取得  
4.  
\[
\bar{X} \pm (臨界値) \times \frac{\sigma \text{ または } s}{\sqrt{n}}
\]

### 仮説検定
1. 帰無仮説 H₀ と対立仮説 H₁ を確認  
2. 両側か片側かを判断  
3. 検定統計量（z または t）を計算  
4. 臨界値と比較して結論

## 【F】典型ミス対策

## 解答・計算の要点

### 問題1
z_{0.025}=1.96  
52 ± 1.96×(10/5) = 52 ± 3.92

### 問題2
z_{0.005}=2.576  
100 ± 2.576×(8/8) = 100 ± 2.576

### 問題3
自由度15、t_{0.025,15} を使用  
60 ± t×(12/4)

### 問題4
自由度9、t_{0.05,9} を使用  
45 ± t×(5/√10)

### 問題5
z=(51−50)/(6/6)=1  
|z| < 1.96 → 棄却されない

### 問題6
z=(58−55)/(10/5)=1.5  
z_{0.01}=2.33 → 棄却されない

### 問題7
t=(72−70)/(4/√20) を計算し、  
|t| と t_{0.025,19} を比較

### 問題8
t=(98−100)/(6/√12) を計算し、  
t と −t_{0.10,11} を比較

### 問題9
1. z検定  
2. t検定（σ未知のため）

### 問題10
分母は σ/√n = 10/5 = 2 とすべき。
