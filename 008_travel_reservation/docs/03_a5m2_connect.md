# A5:SQL Mk-2 導入手順書

前提: `travel_reservation`データベースが構築済みであること。

A5:SQL Mk-2はMySQLへの直接接続に対応しており、ODBCやMySQL Clientの追加インストールは不要。

## 1. ダウンロード

[公式サイト](https://a5m2.mmatsubara.com/index.html)にアクセスし、[Vectorからダウンロード] > [A5:SQL Mk-2(AI無効化版 x64 edition)] > [このソフトを今すぐダウンロード]からダウンロードする。

このリポジトリの動作環境はMySQL 8.0(64bit)のため、**64bit版**を選ぶ。

## 2. インストール手順(Vector版)

1. Vectorのページから最新版のZIPファイルをダウンロードする
2. 分かりやすい場所(例: `C:\A5M2`)に解凍する
3. 解凍したフォルダ内の`A5M2.exe`を実行する(インストーラ不要、そのまま起動可能)
4. 必要であれば`A5M2.exe`のショートカットをデスクトップ等に作成する

## 3. 初回起動時の設定

初回起動時に「ワークスペース情報の保存先」を選ぶ画面が表示される。
既定の「レジストリ」ではなく **「設定ファイル」** を選択して起動する(設定を可搬にでき、PC移行や複数環境での共有がしやすいため)。

## 4. travel_reservationへの接続設定

1. ツールバーの「データベースの追加と削除」を開く
2. 接続方法として **「MySQL (直接接続)」** を選択する
3. 接続情報を入力する

   | 項目 | 値 |
   |---|---|
   | ホスト名 | `localhost` |
   | ポート番号 | `3306` |
   | ユーザーID | `root` |
   | パスワード | [MySQL環境構築手順書]で設定したrootユーザのパスワード |
   | データベース | `travel_reservation` |

4. 「データベース別名」に分かりやすい名前(例: `travel_reservation`)を設定する
5. 接続テストボタンで疎通確認する
6. 問題なければ「OK」で保存する

## 5. 接続確認

1. 左側のデータベースツリーから作成した接続をダブルクリックして接続する
2. `travel_reservation`を展開し、以下の4テーブルが表示されることを確認する
   - `m_user`
   - `m_hotel`
   - `m_accommodation_plan`
   - `t_reservation`
3. 任意のテーブルをダブルクリックし、データが日本語含めて正しく表示されることを確認する
   (A5:SQL Mk-2は既定でUTF-8表示に対応しているため、mysqlの対話コンソールで起きたような
   文字化けは基本的に発生しない)

## 補足

- `ais_admin`ユーザーの権限は`SELECT/INSERT/UPDATE/DELETE`のみのため、テーブル構造の変更(DDL)を
  行いたい場合はrootユーザーで接続する。
