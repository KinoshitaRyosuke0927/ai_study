## 1. この教材について

このコンペは、選手（`player_id`）がコース（`course_id`）を走った際の
タイム（`time_seconds`）を予測する**回帰問題**です。評価指標は RMSE を使用しています。

| データ | 内容 |
|---|---|
| `train_data.csv` | 4,000件（year 1〜5） |
| `test_data.csv` | 160件（**year 6** ※訓練データにない年） |
| 目的変数 | `time_seconds`（連続値） |
| 主な特徴量 | `year`, `quarter`, `session_type`, `player_id`, `course_id` |

このコンペの最大のポイントは、**予測したい対象（test）が訓練データに存在しない
「未知の年（year=6）」である**という点です。この教材では、この制約がモデル選択に
どう影響するかを軸に、4つのモデルを比較していきます。

## 2. データを理解する（EDA）

### 2-1. 基本統計

```
train_data: 20人の選手 × 8コース × 5年(year 1-5) × session_type(practice/tournament)
test_data : 20人の選手 × 8コース × 1年(year 6, tournamentのみ)
```

- `player_id` と `course_id` は train/test で完全に同じ集合（未知カテゴリなし）
- `quarter` は `practice` の行にのみ 1〜4 が入り、`tournament` は常に欠損（NaN）
  → test は全て `tournament` なので、`quarter` は 0 埋めで無害化できる

### 2-2. 発見①：コースごとの差が非常に大きい

```
コース別平均タイム: C5(73秒) 〜 C7(147秒)
コース内の標準偏差: 5〜8秒程度（ばらつきは小さい）
```

→ `course_id` は最も強い予測因子。**加法モデル**（後述）と相性が良い特徴です。

### 2-3. 発見②：選手ごとの実力差がある

選手別の平均タイムは 101〜114秒の範囲でばらつきがあり、上手い選手・苦手な選手が
一貫して存在することが確認できました。

### 2-4. 発見③：年を追うごとにタイムが縮んでいる（かつ、伸び率は逓減）

```
year:  1        2        3        4        5
time: 115.3 → 110.7 → 107.5 → 106.0 → 104.5
diff:     -4.6    -3.2    -1.6    -1.5
```

改善幅がだんだん小さくなる、**収穫逓減（しゅうかくていげん）型のカーブ**です。
「経験を積むほど速くなるが、上達スピード自体は徐々に鈍化する」という現実的な
パターンを表しています。

> **用語: 収穫逓減（diminishing returns）**
> 何かを追加投入（ここでは「経験年数」）しても、得られる効果（タイム短縮幅）が
> だんだん小さくなっていく現象。指数関数的な減衰や `log`、`1/x` のような
> カーブで表現されることが多い。

## 3. 「外挿」という重要な概念

### 3-1. 内挿と外挿の違い

| 用語 | 意味 |
|---|---|
| **内挿（interpolation）** | 学習データの範囲**内**にある値を予測すること |
| **外挿（extrapolation）** | 学習データの範囲**外**にある値を予測すること |

```
学習データの year:  [1, 2, 3, 4, 5]
予測したい year:     6   ← 学習データの範囲の外！＝ 外挿が必要
```

このコンペでは `test_data` の `year` が全て `6` であり、これは train に一度も
登場しない値です。つまり**このコンペは本質的に「外挿」の問題**であり、
モデル選びで最も注意すべきポイントになります。

### 3-2. モデルの種類によって外挿の得意・不得意が異なる

```
線形回帰（Linear Regression）:
  y = a × year + b という直線の式で予測するため、
  year=6 を式にそのまま代入すれば自然に延長できる（外挿が得意）

決定木ベースのモデル（RandomForest, LightGBM など）:
  「year <= 4.5 なら◯◯」のような "分岐" でデータを区切って学習する。
  学習データの最大値（year=5）を超える範囲は分岐のしようがなく、
  year=6 に対しても year=5 と同じような予測値を返してしまう（外挿が不得意）
```

```
       tournament予測
        ↑
  115 ┤●                     Linear: 一次関数で自然に延長できる
      │ ＼
  110 ┤   ●
      │     ＼
  105 ┤       ●___             LightGBM: 学習データの端で
      │           ‾‾‾‾‾‾‾‾●    「横ばい」になり、下降トレンドを
  100 ┤                         引き継げない
      └────┴────┴────┴────┴────┴──→ year
           1    2    3    4    5    6(未知)
```

> **注意**：この図は概念を単純化したものです。実際の検証（5章）では、
> LightGBM は「1年先」という軽度な外挿ではそこまで大きく崩れませんでした。
> 外挿の影響度は「学習範囲からどれだけ離れているか」に依存します。

## 4. モデル改善の変遷

### 4-1. ステップ1：線形回帰（yearをそのまま使用）

最初のベースラインです。`year`, `quarter` を数値特徴量として、
`session_type`, `player_id`, `course_id` をダミー変数化して学習しました。

```python
from sklearn.linear_model import LinearRegression

features = ["year", "quarter"]
categorical = ["session_type", "player_id", "course_id"]
X_train = pd.get_dummies(train_data[features + categorical], columns=categorical)

model = LinearRegression()
model.fit(X_train, y_train)
```

> **用語: ダミー変数（one-hot encoding）**
> 文字列のカテゴリ列（例: `course_id` の "C1", "C2", ...）を、
> 機械学習モデルが扱える数値に変換する方法。カテゴリごとに 0/1 の列を作る。
> ```
> course_id     →  course_id_C1  course_id_C2  course_id_C3 ...
> "C1"                1              0              0
> "C2"                0              1              0
> ```

線形回帰は外挿ができる一方、`year` を直線（一次関数）として扱うため、
実際の「収穫逓減カーブ」を再現できず、精度に限界がありました。

### 4-2. ステップ2：線形回帰（yearを変換）

3章の「収穫逓減カーブ」を線形回帰でも表現できるように、`year` を
`1/year` と `log(year)` に変換して特徴量に追加しました。

```python
df["year_inv"] = 1 / df["year"]
df["year_log"] = np.log(df["year"])
```

```
year:      1     2     3     4     5     6
1/year:  1.00  0.50  0.33  0.25  0.20  0.17   ← 差がだんだん小さくなる
log(year): 0    0.69  1.10  1.39  1.61  1.79   ← 同じく伸びが鈍化する
```

線形回帰の「式に代入するだけで外挿できる」という長所を活かしつつ、
非線形なカーブも表現できるようになり、精度が改善しました。

### 4-3. ステップ3：LightGBM（勾配ブースティング）

決定木ベースのモデルも比較対象として実装しました。

```python
from lightgbm import LGBMRegressor

model = LGBMRegressor(random_state=42)
model.fit(X_train, y_train)
```

> **用語: 勾配ブースティング（Gradient Boosting）**
> 複数の決定木を「前の木の誤差を次の木が修正する」形で順番に学習させる手法。
> LightGBM はその代表的な実装で、テーブルデータに対して非常に高い実績があります。

3-2節で述べた「外挿の弱さ」があるものの、`player_id` × `course_id` の
組み合わせなど、複雑な交互作用を自動的に学習できる強みがあります。

### 4-4. ステップ4：GAM（一般化加法モデル）

線形回帰は `year` の変換を**人間が手動で**（`1/year`, `log(year)` を試して）
見つける必要がありました。GAM はこの変換を**モデルが自動で**学習してくれます。

```python
from pygam import LinearGAM, s, f

# s(0): year を滑らかな非線形カーブとしてフィット
# f(1)〜f(4): カテゴリ変数（session_type, player_id, course_id, quarter）を
#             カテゴリごとの効果として扱う
gam_terms = s(0) + f(1) + f(2) + f(3) + f(4)
model = LinearGAM(gam_terms)
model.fit(X_train, y_train)
```

> **用語: GAM（Generalized Additive Model, 一般化加法モデル）**
> 「各特徴量の効果を足し合わせる」というシンプルな構造は線形回帰と同じですが、
> 各特徴量に対して直線ではなく**滑らかな曲線（スプライン）**を当てはめられる
> モデルです。
> ```
> 線形回帰:  y = a×year + b×player + c×course + ...     （直線の合計）
> GAM    :  y = f1(year) + f2(player) + f3(course) + ...  （曲線の合計）
> ```

> **用語: スプライン（spline）**
> 短い区間ごとに多項式をつなぎ合わせて作る滑らかな曲線。
> 「山や谷のある複雑な形」も、直線を1本引くよりずっと柔軟に表現できます。

GAM は「線形モデルの外挿しやすさ」と「非線形カーブを自動で学習できる柔軟さ」を
両立できる点が最大の利点です。

## 5. 検証方法：未来の年を模した疑似テスト

`test_data` には正解ラベルがないため、「year=6の予測がどれくらい正確か」を
直接確認する方法がありません。そこで、**訓練データの中で同じ状況を再現する**
という工夫をしました。

```
本番の状況:    year 1〜5 で学習 → year 6（未知）を予測
疑似テスト:    year 1〜4 で学習 → year 5（訓練データから除外）を予測
                                    ↑
                              「未知の年」として扱う
```

```python
fit_part = train_data[train_data["year"] <= 4]   # 学習用
valid_part = train_data[train_data["year"] == 5] # 検証用（未知年に見立てる）

model.fit(X_fit, y_fit)
pred = model.predict(X_valid)
rmse = np.sqrt(mean_squared_error(y_valid, pred))
```

この方法により、「実際の外挿状況に近い条件」で各モデルの弱点・強みを
事前に比較できます。

> **用語: ホールドアウト検証（holdout validation）**
> データの一部を意図的に学習から外し、「モデルが見たことのないデータ」として
> 評価に使う手法。今回のように、時間的な区切り（year）でデータを分けて
> 「未来を模した検証」を行うことは、時系列データの検証における定石です。

## 6. 精度比較まとめ

「year=5を未知年に見立てた検証」でのRMSE（小さいほど良い）：

| モデル | RMSE | 外挿へのアプローチ |
|---|---|---|
| 線形回帰（yearそのまま） | 4.359 | 直線のまま延長（カーブを表現できず精度が低い） |
| 線形回帰（year変換） | 3.524 | `1/year`, `log(year)` を手動で追加し、カーブを延長 |
| **GAM** | **3.524** | `year` の非線形カーブを自動学習し、延長 |
| LightGBM | 3.432 | 決定木の分岐（本来は外挿が苦手だが、1年先という軽度な外挿では大きく崩れなかった） |

**わかったこと**：
- `year` を手動で変換した線形回帰と、GAM はほぼ同じ精度でした。
  GAM は変換の試行錯誤（`1/year` にするか `log` にするか等）が不要な分、
  実務的には扱いやすいという利点があります。
- LightGBM は「決定木は外挿が苦手」という理論的な弱点があるものの、
  今回は「1年先」という軽度な外挿だったため、他の特徴量（`player_id`,
  `course_id`）の強い効果に助けられ、大崩れしませんでした。
  → **外挿の影響は「どれだけ範囲外に離れているか」によって変わる**、
    という点は覚えておく価値があります。

## 7. 適したモデル・適さないモデルの整理

### 7-1. このデータの構造の特徴（おさらい）

```
・player_id, course_id ごとの効果がはっきりしていて「足し算」で説明できる（加法的）
・year の効果は滑らかな非線形カーブ（収穫逓減）
・test は訓練データにない未知の year への「外挿」が必要
・データ件数は4,000件と少なめ
```

### 7-2. 適したモデル

| モデル | 適している理由 |
|---|---|
| **GAM**（今回実装） | 加法構造・非線形カーブの両方を自然に表現でき、外挿も可能 |
| **線形回帰 / Ridge / Lasso** | シンプルな加法構造で外挿がしやすい。正則化（Ridge/Lasso）で過学習も抑えられる |
| **混合効果モデル（Mixed Effects Model）** | `player_id` や `course_id` のような「繰り返し測定されるグループ」を扱うのに適した統計モデル。ダミー変数を大量に作らずに、グループごとの効果を推定できる |

### 7-3. 適さないモデルとその理由

| モデル | 適さない理由 |
|---|---|
| **k近傍法（k-NN）** | 「近い年」のデータをそのまま参照するため、未知の年（year=6）に対して原理的に外挿ができない。カテゴリ変数をダミー化すると次元が増え、距離計算も歪みやすい |
| **素の決定木 / RandomForest** | 3章で説明した通り、学習データの範囲外では分岐のしようがなく、外挿ができない |
| **カーネルSVR（RBFカーネル）** | k-NNと同様、局所的な類似度に基づく予測のため外挿が弱い。加えてスケールの異なる特徴量（ダミー変数 × 数値）の扱いに敏感でチューニングの手間が大きい |
| **ディープニューラルネットワーク（MLP）** | データが4,000件と少なく、モデルの表現力に対してデータが不足し過学習しやすい。特別な工夫をしない限り外挿も不安定になりがちで、今回のようなシンプルな加法構造には過剰な複雑さ |

> **共通する考え方**：
> 「学習データの中の似た事例を参照して予測する」タイプのモデル
> （k-NN, カーネルSVR, 決定木ベース）は、**外挿が必要な問題では不利**になりやすい。
> 逆に「数式（関数）としてパターンを学習する」タイプのモデル
> （線形回帰, GAM, 混合効果モデル）は、その数式を延長するだけで
> 自然に外挿できるという利点があります。

## 8. まとめ：学んだこと

1. **「データの構造」を理解してからモデルを選ぶ**
   加法的な効果（選手・コース）と非線形なトレンド（年）が組み合わさったデータには、
   その構造を自然に表現できる GAM や線形モデルが向いていました。

2. **「外挿が必要かどうか」はモデル選びの重要な判断軸**
   test データが訓練データの範囲内（内挿）か範囲外（外挿）かによって、
   得意なモデルの種類が大きく変わります。特に決定木ベースのモデルは
   外挿が原理的に苦手という性質を理解しておくことが重要です。

3. **手元のデータで「未来を模した検証」を作ることで、本番前にリスクを確認できる**
   test に正解がなくても、訓練データの一部を意図的に「未知」として扱うことで、
   外挿性能を事前に見積もることができました。

4. **精度が近い場合は「実装のしやすさ・解釈のしやすさ」も判断材料になる**
   今回、線形回帰（year変換）とGAMはほぼ同精度でした。GAMは変換の試行錯誤が
   不要な分、今後同じような「経年変化」を含むデータに再利用しやすいという
   実務上のメリットがあります。
