## まとめ：貸し出されやすい本の特徴

1. **最近（2020年代）刊行・購入した本** — 新刊ほど需要が高い
2. **単巻（シリーズ物でない）** — シリーズ物より約33%高貸出
3. **社会科学・自然科学・専門書** — 特に法律・生物・化学・図書館学
4. **英語タイトルの洋書** — 日本語タイトルより約19%高貸出
5. **蔵書数1冊のみ** — 希少性が需要を高める可能性

## 予測モデルへの示唆

以下の特徴量が貸出数予測に有効と考えられる。

| 特徴量 | 重要性の根拠 |
|-------|------------|
| 刊行年・購入年 | 年代が新しいほど高貸出 |
| NDC分類（大分類・細分類） | 分類によって大きな差がある |
| シリーズ有無（巻数の有無） | 単巻 vs シリーズで約3pt差 |
| 蔵書数 | 少ないほど高貸出 |
| タイトルの言語（日本語/英語） | 英語タイトルがやや高め |
