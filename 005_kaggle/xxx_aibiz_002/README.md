# JEPX 東京エリア 電力スポット価格予測コンペティション

## 概要

本コンペティションは、JEPX（日本卸電力取引所）で取引される東京エリアの電力スポット価格（円/kWh）を、過去の取引データ・電力需給データ・気象データから予測することを目的としています。

電力スポット価格は需給バランス・気象条件・季節性など多数の要因が複合的に影響するため、時系列的な特性と各種外部データを組み合わせた予測モデルの構築が求められます。

### スコア評価指標

予測精度の評価には **RMSE（Root Mean Squared Error）** を使用します。

$$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2}$$

スコアが小さいほど予測精度が高いことを示します。

## データ

### 学習データ（pre_eval.csv）

- **期間**：2024/4/1 〜 2026/3/31
- **行数**：35,040行（48コマ/日 × 730日）
- **目的変数**：`tokyo_price`（東京エリアスポット価格、円/kWh）

### テストデータ（test_eval.csv）

- **期間**：2026/4/1 〜 2026/5/29
- **行数**：2,832行（48コマ/日 × 59日）
- **内容**：`tokyo_price` 列を除いた学習データと同一の特徴量

## 列の説明

### 共通列（学習・テストデータ）

| 列名 | 説明 | 単位 |
|---|---|---|
| `id` | レコードの一意識別子 | - |
| `date` | 取引日（YYYY/MM/DD形式） | - |
| `frame` | 取引コマ番号（1〜48）。1コマ=30分。1=0:00〜0:30、2=0:30〜1:00、…、48=23:30〜24:00 | - |
| `dayofweek` | 曜日（0=月曜〜6=日曜） | - |
| `is_holiday` | 祝日フラグ（1=祝日、0=平日） | - |
| `temp` | 東京の気温（当該コマ時点の実測値） | ℃ |
| `weather` | 東京の天気（英語名称） | - |
| `power_result` | 東京エリアの電力需要実績 | 万kW |
| `power_prediction` | 東京エリアの電力需要予測値 | 万kW |
| `usage_rate` | 電力使用率（需要実績 ÷ 供給力） | - |
| `power_supply` | 東京エリアの供給力 | 万kW |
| `sell_amount` | 売り申込量 | kWh |
| `buy_amount` | 買い申込量 | kWh |
| `contracted_amount` | 約定量 | kWh |

### 学習データのみの列

| 列名 | 説明 | 単位 |
|---|---|---|
| `tokyo_price` | 東京エリアスポット価格（**予測対象**） | 円/kWh |

## データ取得元

| データ種別 | 取得元 |
|---|---|
| 電力スポット価格・売買申込量・約定量 | [JEPX（日本卸電力取引所）](https://www.jepx.jp/) スポット市場 取引結果 |
| 電力需要実績・予測・供給力・使用率 | [東京電力パワーグリッド「でんき予報」](https://www.tepco.co.jp/forecast/) |
| 気温・天気 | [気象庁 過去の気象データ](https://www.data.jma.go.jp/stats/etrn/index.php)（東京観測所、AMeDAS） |
| 祝日情報 | 内閣府「国民の祝日」をもとに [jpholiday](https://github.com/Lalcs/jpholiday) ライブラリで付与 |
