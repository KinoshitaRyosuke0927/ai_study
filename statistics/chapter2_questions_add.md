### 問題20（記述・計算）
4択クイズを2問解く。まったく知識がなく、ランダムに選ぶとする。

2. 少なくとも1問正解する確率

---

## 解答

### A 基本確率

**問題1**
3の倍数：3, 6, 9 → 3個
P = 3/10 **→ C**

**問題2**
白+青 = 3+2 = 5個
P = 5/10 = **1/2 → A**

**問題3**
2の倍数：{2,4,6}、3の倍数：{3,6}、両方：{6}
P(A∪B) = 3/6 + 2/6 − 1/6 = **4/6 = 2/3 → A**

**問題4**
どちらかが得意な人 = 40+50−20 = 70人
どちらも得意でない = 100−70 = 30人 → 30/100 = **0.30 → B**

---

### B 余事象の利用

**問題5**
$P(\text{少なくとも1回表}) = 1 - P(\text{全て裏}) = 1 - (1/2)^5$
**→ A**

**問題6**
$P(\text{少なくとも1個不良}) = 1 - P(\text{全て良品}) = 1 - 0.9^3$
**→ A**

**問題7**
$P(\text{少なくとも1回成功}) = 1 - P(\text{全て失敗}) = 1 - 0.4^4 = 1 - 0.0256 = 0.9744$

---

### C 加法定理

**問題8**
P(A∪B) = 0.5 + 0.4 − 0.25 = **0.65 → C**

**問題9**
排反なので P(A∩B) = 0
P(A∪B) = 0.3 + 0.4 = **0.70 → C**

**問題10**
P(A∩B) = P(A) + P(B) − P(A∪B) = 0.4 + 0.5 − 0.75 = **0.15**
独立性の確認：P(A)P(B) = 0.4 × 0.5 = 0.20 ≠ 0.15 → **独立でない**

---

### D 条件付き確率

**問題11**
P(A|B) = P(A∩B)/P(B) = 0.12/0.4 = **0.30 → B**

**問題12**
1枚目が白（6個中）のとき、残り9個中白は5個
P(2枚目が白|1枚目が白) = **5/9 ≈ 0.556**

**問題13**
$P(\text{少なくとも1人合格}) = 1 - P(\text{2人とも不合格}) = 1 - 0.4^2 = 1 - 0.16 = 0.84$
**→ C**

**問題14**
全確率の公式：
$P(\text{部活}) = P(\text{部活}|\text{男子}) \times P(\text{男子}) + P(\text{部活}|\text{女子}) \times P(\text{女子})$
$= 0.40 \times 0.60 + 0.30 \times 0.40 = 0.24 + 0.12 = 0.36$

---

### E 乗法定理・独立性

**問題15**
独立なので P(A∩B) = P(A)P(B) = 0.4 × 0.5 = **0.20 → B**

**問題16**
P(A)P(B) = 0.5 × 0.4 = 0.20 = P(A∩B) → **独立である → A**

**問題17**
1. ちょうど2回表：$\binom{3}{2}(1/2)^2(1/2)^1 = 3/8$
2. 最初が表・残り2回が裏：$(1/2)(1/2)^2 = 1/8$

---

### F ベイズの定理

**問題18**
$P(D) = 0.02$、$P(+|D) = 0.98$、$P(+|D^c) = 0.05$

$P(+) = 0.98 \times 0.02 + 0.05 \times 0.98 = 0.0196 + 0.049 = 0.0686$

$P(D|+) = \frac{0.0196}{0.0686} \approx 0.286 \approx 28.6\%$
**→ A**

**問題19**
$P(\text{不良}) = 0.02 \times 0.70 + 0.05 \times 0.30 = 0.014 + 0.015 = 0.029$

$P(B|\text{不良}) = \frac{0.05 \times 0.30}{0.029} = \frac{0.015}{0.029} \approx 0.517 \approx 51.7\%$

**問題20**
1. $P(\text{2問正解}) = (1/4)^2 = 1/16 = 0.0625$
2. $P(\text{少なくとも1問正解}) = 1 - P(\text{2問とも不正解}) = 1 - (3/4)^2 = 1 - 9/16 = 7/16 = 0.4375$
