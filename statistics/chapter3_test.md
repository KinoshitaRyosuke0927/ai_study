## 主要問題の解説

### 問題4
$E[X] = 0 \times 0.3 + 2 \times 0.5 + 4 \times 0.2 = 0 + 1.0 + 0.8 = 1.8$ **→ C**

### 問題5
$E[X^2] = 0^2 \times 0.3 + 2^2 \times 0.5 + 4^2 \times 0.2 = 0 + 2.0 + 3.2 = 5.2$

$Var(X) = 5.2 - 1.8^2 = 5.2 - 3.24 = 1.96$

※選択肢に 1.96 が無ければ最近似のCを選ぶ（計算精度の差に注意）

実際の値：$Var(X) = 1.96$

### 問題6
Var(X) = E[X²] − (E[X])² ≥ 0 → E[X²] ≥ (E[X])² が常に成り立つ **→ B**

### 問題8
$P(X=3) = \binom{5}{3}0.4^3 \times 0.6^2 = 10 \times 0.064 \times 0.36 = 10 \times 0.02304 = 0.2304$ **→ B**

### 問題9
$P(X \geq 3) = P(X=3) + P(X=4)$
$= \binom{4}{3}(1/2)^4 + \binom{4}{4}(1/2)^4 = 4/16 + 1/16 = 5/16 = 0.3125$ **→ D**

### 問題13
$P(X \geq 1) = 1 - P(X=0) = 1 - e^{-3}$ **→ B**

### 問題14
$Z = (72-60)/8 = 12/8 = 1.5$ **→ C**

### 問題16
$Z_1 = (40-50)/10 = -1$、$Z_2 = (60-50)/10 = 1$
$P(40 \leq X \leq 60) = P(-1 \leq Z \leq 1)$ **→ A**

### 問題17
「上位5%」= P(X > x) = 0.05 → P(X ≤ x) = 0.95
→ P(Z ≤ z) = 0.95 となる z を表から読み、x = μ + zσ **→ B**

### 問題18
右裾が長い → 大きい外れ値が平均を引き上げる
→ 平均 > 中央値 > 最頻値 **→ B**
