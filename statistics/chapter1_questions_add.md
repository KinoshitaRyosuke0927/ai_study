## 解答

### A 代表値

**問題1**
合計 = 3+7+5+7+2+8+4 = 36、n=7
→ 平均 = 36/7 ≈ **5.14**
**→ C**

**問題2**
昇順：4, 7, 8, 11, 15, 19, 23、n=7、4番目 = **11**
**→ B**

**問題3**
4が4回（最多）→ 最頻値 = **4**
**→ C**

**問題4**
$\frac{60 \times 1 + 70 \times 2 + 80 \times 3 + 90 \times 4}{1+2+3+4} = \frac{60+140+240+360}{10} = \frac{800}{10} = 80$
**→ C**

**問題5**
平均 = (2+4+6+8+100)/5 = 120/5 = 24
中央値 = 3番目 = 6
→ **中央値（6）が適切**。100という外れ値が平均（24）を大きく引き上げており、実態（大半が10未満）を反映していない。外れ値の影響を受けにくい中央値が適切。

---

### B 分散・標準偏差

**問題6**
平均 = 5
偏差の二乗：16+4+0+4+16 = 40
$\sigma^2 = 40/5 = $ **8**
**→ C**

**問題7**
平均 = 5
偏差の二乗：9+1+1+9 = 20
$s^2 = 20/(4-1) = 20/3 ≈ 6.67$
**→ C**

**問題8**
$\sigma_A = 2\sigma_B$ → $\sigma_A^2 = 4\sigma_B^2$ → **4倍**
**→ C**

**問題9**
平均 = 30
偏差の二乗：400+100+0+100+400 = 1000
$\sigma^2 = 1000/5 = 200$
$\sigma = \sqrt{200} = 10\sqrt{2} \approx 14.14$

**問題10**
すべての値が同じなので偏差 = 0 → 分散 = **0**
**→ A**

---

### C 四分位数・IQR

**問題11**
n=7、中央値 = 4番目 = **15**
**→ B**

**問題12**
下半分：3, 7, 11（3個）→ Q1 = 2番目 = **7**
**→ A**

**問題13**
昇順：2, 5, 6, 7, 9, 12, 14, 15, 60（n=9）
- Q2 = 5番目 = **9**
- Q1 = 下半分(2,5,6,7)の中央 = (5+6)/2 = **5.5**
- Q3 = 上半分(12,14,15,60)の中央 = (14+15)/2 = **14.5**
- IQR = 14.5 − 5.5 = **9**
- 外れ値の下限：5.5 − 1.5×9 = 5.5−13.5 = −8
- 外れ値の上限：14.5 + 1.5×9 = 14.5+13.5 = **28**
- 60 > 28 → **60は外れ値**

**問題14**
IQR = 40−20 = 20
上限 = 40 + 1.5×20 = 40+30 = **70**
**→ D**

---

### D 度数分布・ヒストグラム

**問題15** → **B**（階級値）

**問題16**
12/60 = **0.20**
**→ C**

**問題17**
$$\bar{x} \approx \frac{45 \times 2 + 55 \times 8 + 65 \times 14 + 75 \times 10 + 85 \times 6}{40} = \frac{90+440+910+750+510}{40} = \frac{2700}{40} = 67.5$$

**問題18** → **C**（度数密度）

**問題19**
度数密度 = 度数/階級幅 = 10/20 = **0.5**

---

### E 標準化・変動係数

**問題20**
Z = (75−60)/10 = 15/10 = **1.5**
**→ B**

**問題21** → **B**（平均より2標準偏差低い）

**問題22**
$CV_A = 5/50 \times 100 = 10\%$
$CV_B = 8/100 \times 100 = 8\%$
→ **A班の方が相対的にばらつきが大きい**
**→ C**

**問題23**
- 数学のZ = (78−60)/12 = 18/12 = **1.5**
- 英語のZ = (86−70)/8 = 16/8 = **2.0**
→ **英語の方が相対的に良い成績**（平均から2標準偏差上）
