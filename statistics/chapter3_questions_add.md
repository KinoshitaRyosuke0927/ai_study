# 第3章 確率分布 ― 追加演習（正規分布・Z表使用）

本資料は、第3章「確率分布」の内容を踏まえ、  
**標準正規分布表（Z表）が与えられている前提**で、  
正規分布の確率計算に慣れることを目的とした演習問題集です。

※ Z表は  
- P(Z ≤ z)  
- または P(0 ≤ Z ≤ z)  
のいずれかが与えられているものとし、問題文の指示に従って利用してください。

---

## 演習の基本方針（重要）

正規分布の問題は、必ず次の手順で解きましょう。

1. 求めたい確率を **X の不等式**で表す  
2. Z = (X − μ) / σ により **標準化**する  
3. Z の不等式に対応する **Z表の値を読む**  
4. 必要に応じて  
   - 補集合（1 − …）  
   - 対称性  
   を用いて調整する  

---

## 【基礎】標準化の確認

### 問題1
X が正規分布 N(50, 10²) に従うとする。  
x = 65 を標準化したときの Z の値を求めなさい。

**解答例**  
Z = (65 − 50) / 10 = 1.5

---

### 問題2
X が N(100, 20²) に従うとする。  
x = 70 を標準化したときの Z の値を求めなさい。

---

## 【片側確率】P(X ≤ a), P(X ≥ a)

### 問題3
X ~ N(50, 10²) とする。  
P(X ≤ 60) を求めなさい。

**ヒント**  
- まず Z に変換する  
- Z表が P(Z ≤ z) の形式かどうかを確認する  

---

### 問題4
X ~ N(70, 5²) とする。  
P(X ≥ 75) を求めなさい。

**注意**  
「以上」は **補集合**を使うと計算が簡単になる。

---

## 【両側確率】P(a ≤ X ≤ b)

### 問題5
X ~ N(100, 10²) とする。  
P(90 ≤ X ≤ 110) を求めなさい。

**ヒント**  
- 2つの Z 値を求める  
- 差を取る  

---

### 問題6
X ~ N(60, 8²) とする。  
P(52 ≤ X ≤ 68) を求めなさい。

---

## 【対称性の利用】

### 問題7
Z ~ N(0,1) とする。  
P(Z ≥ 1.2) を Z表を用いて求めなさい。

**ヒント**  
P(Z ≥ 1.2) = 1 − P(Z ≤ 1.2)

---

### 問題8
Z ~ N(0,1) とする。  
P(−1.5 ≤ Z ≤ 1.5) を求めなさい。

**ヒント**  
- 対称性を使う  
- P(−a ≤ Z ≤ a) = 2P(0 ≤ Z ≤ a)

---

## 【典型ミス対策】

### 問題9
次の計算手順の誤りを指摘しなさい。

> X ~ N(80, 4²)  
> P(X ≥ 84) を求める  
> Z = (84 − 80) / 4² = 0.25

---

### 問題10
次のうち、正規分布の確率計算として誤っている説明を1つ選びなさい。

A. Z変換では分母に標準偏差を用いる  
B. P(X = a) は 0 である  
C. P(X ≥ a) は常に Z表の値そのままで求められる  
D. 両側確率は差や対称性を使って求める

X ~ N(100, 15²) とする。  
上位 10% に入る値 x を求める考え方を説明しなさい。

### 問題12

## 解答・解説（要点）

### 問題2
Z = (70 − 100) / 20 = −1.5

### 問題3
Z = (60 − 50) / 10 = 1  
P(X ≤ 60) = P(Z ≤ 1)

### 問題4
Z = (75 − 70) / 5 = 1  
P(X ≥ 75) = 1 − P(Z ≤ 1)

### 問題5
Z1 = (90 − 100) / 10 = −1  
Z2 = (110 − 100) / 10 = 1  
P(90 ≤ X ≤ 110) = P(−1 ≤ Z ≤ 1)

### 問題6
Z1 = (52 − 60) / 8 = −1  
Z2 = (68 − 60) / 8 = 1

### 問題7
1 − P(Z ≤ 1.2)

### 問題8
2P(0 ≤ Z ≤ 1.5)

### 問題9
分母は分散ではなく **標準偏差 4** を用いるべき。

### 問題10
C

### 問題11
P(Z ≤ z) = 0.9 となる z を Z表から求め、  
x = μ + zσ と逆変換する。

### 問題12
Z = (80 − 60) / 12  
P(X ≥ 80) = 1 − P(Z ≤ (80 − 60) / 12)
