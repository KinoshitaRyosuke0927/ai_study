# 第5章 相関・回帰分析 ― 解説編（詳細版）

本章では、2つの量的変数の関係を分析するための
**相関分析・回帰分析**を学びます。
統計検定2級では、
- 指標の意味理解
- 計算結果の解釈
- 検定の手順
が特に重視されます。

> 重要：相関は「関係の強さ」、回帰は「予測」。この違いを軸に整理しましょう。

---

## 5-1 相関関係と散布図

### 相関関係

2つの変数 X, Y が**一緒に変化する傾向**を表す。

| 種類 | 説明 | 散布図の形 |
|------|------|-----------|
| 正の相関 | Xが増えるとYも増える | 右上がり |
| 負の相関 | Xが増えるとYが減る | 右下がり |
| 無相関 | XとYに線形関係がない | ランダム |

**重要**：相関は原因・結果を意味しない（相関 ≠ 因果関係）

**疑似相関（見せかけの相関）**：第三の変数（交絡因子）が両方に影響しているために生じる相関。

例：「アイスクリームの売上」と「水難事故件数」は正の相関があるが、原因は「気温」という共通因子。

### 散布図のポイント

- 外れ値（他の点から大きく外れた点）を確認する
- 線形でない関係（曲線的）がないか確認する
- データのクラスタリングがないか確認する

---

## 5-2 共分散

2変数の「一緒に変化する傾向」を数値化したもの：

$$Cov(X,Y) = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})$$

（不偏共分散の場合は分母 $n-1$）

| 値 | 意味 |
|----|------|
| $Cov > 0$ | Xが大きいときYも大きい傾向 |
| $Cov < 0$ | Xが大きいときYが小さい傾向 |
| $Cov = 0$ | 線形関係なし（独立とは異なる） |

**欠点**：単位を持つため、スケールが変わると値が変わる。異なる変数間の比較に使えない。

**計算例**

データ（n=3）：

| $x_i$ | $y_i$ | $x_i - \bar{x}$ | $y_i - \bar{y}$ | 積 |
|--------|--------|-----------------|-----------------|-----|
| 2 | 3 | −2 | −2 | 4 |
| 4 | 5 | 0 | 0 | 0 |
| 6 | 7 | 2 | 2 | 4 |
| 合計 | | 0 | 0 | 8 |

$\bar{x} = 4, \bar{y} = 5$

$Cov(X,Y) = \frac{8}{3} \approx 2.67$（分母3の場合）

---

## 5-3 相関係数

### ピアソンの積率相関係数

$$r = \frac{Cov(X,Y)}{\sigma_X \sigma_Y} = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2 \cdot \sum(y_i - \bar{y})^2}}$$

**特徴**

| 性質 | 説明 |
|------|------|
| 範囲 | $-1 \leq r \leq 1$ |
| 単位 | なし（無次元） |
| $r = 1$ | 完全な正の線形関係 |
| $r = -1$ | 完全な負の線形関係 |
| $r = 0$ | 線形関係なし |

**相関の強さの目安**

| $|r|$ の値 | 解釈 |
|-----------|------|
| 0.7〜1.0 | 強い相関 |
| 0.4〜0.7 | 中程度の相関 |
| 0.2〜0.4 | 弱い相関 |
| 0.0〜0.2 | ほとんど相関なし |

**注意点**

- 外れ値の影響を受けやすい（1点だけで大きく変わることがある）
- **非線形関係は捉えられない**（r ≈ 0でも曲線的な関係がある場合あり）
- 相関係数は直線的関係の強さのみを測る

**計算例**

上の例より：$\sum(x_i - \bar{x})^2 = 8$、$\sum(y_i - \bar{y})^2 = 8$、$\sum(x_i-\bar{x})(y_i-\bar{y}) = 8$

$$r = \frac{8}{\sqrt{8 \times 8}} = \frac{8}{8} = 1.0$$

（完全な正の線形関係）

## 5-4 単回帰分析

### 回帰直線

$$\hat{y} = a + bx$$

- $b$：回帰係数（傾き）— x が1増えたときの y の変化量
- $a$：切片 — x = 0 のときの y の値

### 最小二乗法

観測値 $y_i$ と予測値 $\hat{y}_i = a + bx_i$ の**残差二乗和を最小にする** a, b を求める：

$$S = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \sum_{i=1}^n (y_i - a - bx_i)^2 \to \min$$

### 回帰係数の計算式

$$b = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = \frac{Cov(X,Y)}{Var(X)} = r \cdot \frac{\sigma_Y}{\sigma_X}$$

$$a = \bar{y} - b\bar{x}$$

**重要な性質**：回帰直線は必ず $(\bar{x}, \bar{y})$ を通る。

**計算例**

データ（n=5）：

| $x_i$ | $y_i$ | $x_i - \bar{x}$ | $y_i - \bar{y}$ | $(x_i-\bar{x})^2$ | $(x_i-\bar{x})(y_i-\bar{y})$ |
|--------|--------|-----------------|-----------------|-------------------|-------------------------------|
| 1 | 2 | −2 | −3.2 | 4 | 6.4 |
| 2 | 4 | −1 | −1.2 | 1 | 1.2 |
| 3 | 5 | 0 | −0.2 | 0 | 0 |
| 4 | 7 | 1 | 1.8 | 1 | 1.8 |
| 5 | 8 | 2 | 2.8 | 4 | 5.6 |
| 合計 | | 0 | 0 | **10** | **15** |

$\bar{x} = 3, \bar{y} = 5.2$

$$b = \frac{15}{10} = 1.5, \quad a = 5.2 - 1.5 \times 3 = 0.7$$

**回帰直線：$\hat{y} = 0.7 + 1.5x$**

### 残差（Residual）

$$e_i = y_i - \hat{y}_i$$

残差の性質：
- $\sum e_i = 0$（残差の和は0）
- $\sum x_i e_i = 0$（説明変数と残差は無相関）

## 5-5 回帰係数の解釈

$$\hat{y} = a + bx$$

| 状況 | 解釈 |
|------|------|
| $b > 0$ | xが1増えるとyが $b$ 増える |
| $b < 0$ | xが1増えるとyが $|b|$ 減る |
| $b = 0$ | xとyに線形関係なし（回帰直線は水平） |

**注意**：bの大きさ（絶対値）は単位に依存するため、異なる変数間の比較には標準化回帰係数を使う。

**計算例の解釈**

$\hat{y} = 0.7 + 1.5x$ の場合：
- xが1増えると、yは平均して1.5増える（と予測される）
- x = 0 のときのyの予測値は 0.7

---

## 5-6 決定係数 R²

回帰式が目的変数 y の変動をどれだけ説明できているかを表す指標：

$$R^2 = r^2 = 1 - \frac{SS_{res}}{SS_{total}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

- 単回帰では $R^2 = r^2$（相関係数の二乗）
- 範囲：$0 \leq R^2 \leq 1$

**解釈**：y の全変動のうち、$R^2 \times 100$% を回帰式が説明している

| $R^2$ | 解釈 |
|-------|------|
| 0.9以上 | 非常に当てはまりが良い |
| 0.7〜0.9 | 当てはまりが良い |
| 0.5〜0.7 | 中程度 |
| 0.5未満 | 当てはまりが弱い |

**計算例**
r = 0.8 のとき：$R^2 = 0.64$
→ y の変動の64%を x で説明できている

**陥りやすい間違い**
- 「R² = 0.64 なら64%正確に予測できる」は不正確（変動の説明率）
- 変数を増やすと R² は必ず上がる（重回帰で問題になる）

## 5-7 相関・回帰の検定

### 相関係数の有意性検定

**帰無仮説**：母相関係数 $\rho = 0$（相関なし）
**対立仮説**：$\rho \neq 0$（通常は両側）

**検定統計量**：

$$t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}}$$

これは**自由度 $n-2$ の t分布**に従う。

**検定手順**
1. 上式で t を計算
2. 自由度 $n-2$ のt表から臨界値を読む
3. $|t| > t_{\alpha/2, n-2}$ なら棄却（相関が有意）

**計算例**

n=22、r=0.5 のとき：

$$t = \frac{0.5\sqrt{22-2}}{\sqrt{1-0.25}} = \frac{0.5\sqrt{20}}{\sqrt{0.75}} = \frac{0.5 \times 4.47}{0.866} \approx 2.58$$

自由度20の $t_{0.025,20} = 2.086$ として：
$|t| = 2.58 > 2.086$ → 有意水準5%で有意（相関あり）

### 回帰係数の検定

**帰無仮説**：$b = 0$（xとyに線形関係なし）

相関係数の検定と同等の t 検定を用いる。

### 自由度が n−2 になる理由

回帰直線 $y = a + bx$ のパラメータ（aとb）を2つ推定するため、自由度が2減る。

## 5-8 相関分析と回帰分析の比較

| 項目 | 相関分析 | 回帰分析 |
|------|----------|----------|
| 目的 | 関係の強さ・方向を測る | 一方から他方を予測する |
| 変数の役割 | X, Y は対称 | X は説明変数、Y は目的変数（非対称） |
| 主な指標 | 相関係数 r | 回帰係数 b、決定係数 R² |
| 因果関係 | 示せない | 示せない |
