## 解説

### 問題1
平均 = (4+8+6+10+12)/5 = 40/5 = 8

不偏分散（分母 n−1 = 4）：
$$s^2 = \frac{(4-8)^2+(8-8)^2+(6-8)^2+(10-8)^2+(12-8)^2}{4} = \frac{16+0+4+4+16}{4} = \frac{40}{4} = 10 \quad \textbf{→ B}$$

### 問題2
昇順：2, 5, 6, 8, 10, 14, 18（n=7）
- 中央値 = 4番目 = 8
- Q1 = 下半分（2, 5, 6）の中央 = 5
- Q3 = 上半分（10, 14, 18）の中央 = 14
- IQR = 14 − 5 = **9 → A**

### 問題3
$$Z = \frac{73 - 50}{10} = \frac{23}{10} = 2.3 \quad \textbf{→ C}$$

### 問題4
$$\bar{x} = \frac{30 \times 5 + 50 \times 15 + 70 \times 20 + 90 \times 10}{5+15+20+10} = \frac{150+750+1400+900}{50} = \frac{3200}{50} = 62.0 \quad \textbf{→ B}$$

### 問題5
$$P(A \cup B) = 0.5+0.6-0.3 = 0.8$$
$$P(A^c \cap B^c) = P((A \cup B)^c) = 1 - 0.8 = 0.20 \quad \textbf{→ C}$$

### 問題6
$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} = \frac{0.7 \times 0.3}{0.35} = \frac{0.21}{0.35} = 0.60 \quad \textbf{→ D}$$

### 問題7
$P(D) = 0.02$、$P(+|D) = 0.98$、$P(+|D^c) = 0.05$

$$P(+) = 0.98 \times 0.02 + 0.05 \times 0.98 = 0.0196 + 0.049 = 0.0686$$
$$P(D|+) = \frac{0.0196}{0.0686} \approx 0.286 \approx 29\% \quad \textbf{→ B}$$

### 問題8
$$P(X=3) = \binom{10}{3}0.3^3 \times 0.7^7 = 120 \times 0.027 \times 0.0824 = 120 \times 0.002224 \approx 0.2668 \quad \textbf{→ C}$$

（$0.7^7 = 0.7^4 \times 0.7^3 = 0.2401 \times 0.343 \approx 0.0824$）

### 問題9
$$P(X \geq 4) = P(X=4) + P(X=5)$$
$$= \binom{5}{4}(0.5)^5 + \binom{5}{5}(0.5)^5 = 5 \times \frac{1}{32} + \frac{1}{32} = \frac{6}{32} = \frac{3}{16} = 0.1875 \quad \textbf{→ D}$$

### 問題10
$E[X] = np = 4$、$Var(X) = np(1-p) = 3.2$

$\frac{Var(X)}{E[X]} = 1-p = \frac{3.2}{4} = 0.8$ → **p = 0.2**
$n = \frac{4}{0.2} = 20$ → **n = 20、p = 0.20 → B**

### 問題11
$$P(X=2) = \frac{e^{-3} \cdot 3^2}{2!} = \frac{0.0498 \times 9}{2} = \frac{0.4482}{2} = 0.2241 \approx 0.2240 \quad \textbf{→ E}$$

※ 解答一覧では C（0.0747）を示しているが、正しくはE（0.2240）。正確な答えは **0.2240 → E**。

正しい解答一覧：問題11 → **E**

### 問題12
$$P(X \leq 1) = P(X=0) + P(X=1) = e^{-2} + 2e^{-2} = 3e^{-2} \quad \textbf{→ C}$$

（$P(X=0) = e^{-2}$、$P(X=1) = e^{-2} \cdot 2$）

### 問題13
$$E[X] = 1 \times 0.1 + 2 \times 0.3 + 3 \times 0.4 + 4 \times 0.2 = 0.1+0.6+1.2+0.8 = 2.7$$
$$E[X^2] = 1 \times 0.1 + 4 \times 0.3 + 9 \times 0.4 + 16 \times 0.2 = 0.1+1.2+3.6+3.2 = 8.1$$
$$Var(X) = E[X^2] - (E[X])^2 = 8.1 - 2.7^2 = 8.1 - 7.29 = 0.81 \quad \textbf{→ B}$$

### 問題14
$$Z = \frac{98-80}{12} = \frac{18}{12} = 1.5 \quad \textbf{→ C}$$

### 問題15
$$Z_1 = \frac{52-60}{8} = -1, \quad Z_2 = \frac{76-60}{8} = 2$$
$$P(52 \leq X \leq 76) = P(-1 \leq Z \leq 2) = P(Z \leq 2) - P(Z \leq -1)$$
$$= 0.9772 - (1-0.8413) = 0.9772 - 0.1587 = 0.8185 \quad \textbf{→ B}$$

### 問題16
「上位 2.5%」→ P(X > x₀) = 0.025 → P(Z ≤ z₀) = 0.975 → z₀ = 1.96
$$x_0 = \mu + 1.96\sigma \quad \textbf{→ D}$$

### 問題17
$$SE = 20/\sqrt{100} = 2$$
$$99\%\text{CI} = 135 \pm 2.576 \times 2 = 135 \pm 5.152 \quad \textbf{→ C}$$

### 問題18
幅の条件：$2 \times 1.96 \times \frac{15}{\sqrt{n}} \leq 6$
$$\sqrt{n} \geq \frac{2 \times 1.96 \times 15}{6} = \frac{58.8}{6} = 9.8$$
$$n \geq 9.8^2 = 96.04 \quad \to \quad n_{\min} = 97 \quad \textbf{→ B}$$

ただし実務的には $n = 97$ が最小だが、選択肢では D（144）と見えるため、条件を半幅 6 とした場合を再確認：
半幅 ≤ 3 → $\sqrt{n} \geq 1.96 \times 15 / 3 = 9.8$ → $n \geq 97$ → **B（97）→ B**

### 問題19
$$SE = s/\sqrt{n} = 6/\sqrt{9} = 6/3 = 2$$
$$95\%\text{CI} = 25 \pm 2.306 \times 2 = 25 \pm 4.612 \quad \textbf{→ C}$$

### 問題20
$$SE = \sigma/\sqrt{n} = 5/\sqrt{25} = 1$$
$$z = \frac{48-50}{1} = -2.0$$
$|z| = 2.0 > 1.96$ → **H₀ を棄却 → B**

### 問題21
$$SE = s/\sqrt{n} = 8/\sqrt{16} = 2$$
$$t = \frac{55-52}{2} = 1.5$$
片側検定（H₁: μ > 52）：$t_{0.05,15} = 1.753$

$t = 1.5 < 1.753$ → H₀ 棄却しない

※ 問題文の選択肢より t = 1.5 で「H₀ 棄却しない → A」
解答一覧の E（t = 3.00、H₀ 棄却する）は別の数値設定のケース。**正解は A**。

正しい解答：問題21 → **A**

### 問題22
$$SE = \sqrt{\hat{p}(1-\hat{p})/n} = \sqrt{0.45 \times 0.55/200} = \sqrt{0.2475/200} = \sqrt{0.0012375} \approx 0.03518$$
$$\text{幅} = 2 \times 1.96 \times 0.03518 \approx 2 \times 0.0689 \approx 0.138$$

※ 幅（区間の長さ）= 約 0.138。片側の誤差が 0.069 なので、**幅 ≈ 0.138 → D**

正しい解答：問題22 → **D**

| −2 | −2 | 4 |
| 0 | 2 | 0 |

**→ B（b = 1.5、a = 0.5）**

### 問題27
$$t = \frac{0.35\sqrt{32-2}}{\sqrt{1-0.35^2}} = \frac{0.35\sqrt{30}}{\sqrt{1-0.1225}} = \frac{0.35 \times 5.477}{\sqrt{0.8775}} = \frac{1.917}{0.9368} \approx 2.05 \approx 2.01 \quad \textbf{→ B}$$

（$\sqrt{30} \approx 5.477$、$\sqrt{0.8775} \approx 0.937$）

$t \approx 2.01 < 2.042 = t_{0.025,30}$

※ t ≈ 2.01 < 2.042 → H₀ 棄却しない → **A**

ただし問題27の正確な計算では t ≈ 2.05 > 2.042 → H₀ 棄却 → **B**
（計算精度により B が正解）**→ B**

### 問題29
