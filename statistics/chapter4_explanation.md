# 第4章 推測統計 ― 解説編（詳細版）

本章では、統計検定2級の**最重要分野**である推測統計を扱います。
推測統計では、標本から母集団の性質を推測するために、
- 標本分布
- 区間推定
- 仮説検定
を体系的に学びます。

> 重要：「どの分布を使うか」「式の構造の意味」「なぜその判断をするか」まで理解することが得点に直結します。

---

## 4-1 母集団・標本・統計量

| 用語 | 定義 | 例 |
|------|------|-----|
| **母集団** | 分析対象となる全体 | 日本の全成人の身長 |
| **標本** | 母集団から抽出した一部 | 100人の身長データ |
| **母数（パラメータ）** | 母集団の特性値（未知） | 母平均μ、母分散σ² |
| **統計量** | 標本から計算される量（既知） | 標本平均 $\bar{X}$、不偏分散 $s^2$ |

### 不偏分散（標本分散）

$$s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$

> 分母が $n-1$ なのは「不偏性」を保証するため。$E[s^2] = \sigma^2$ が成り立つ。分母 $n$ では平均的に母分散を過小評価してしまう。

**計算例**
データ：3, 5, 7, 9（n=4、$\bar{x} = 6$）

$$s^2 = \frac{(3-6)^2 + (5-6)^2 + (7-6)^2 + (9-6)^2}{4-1} = \frac{9+1+1+9}{3} = \frac{20}{3} \approx 6.67$$

## 4-2 標本分布と中心極限定理

### 標本平均の分布

母集団の平均μ、分散σ²から大きさnの標本をランダム抽出するとき：

$$E[\bar{X}] = \mu, \quad Var(\bar{X}) = \frac{\sigma^2}{n}$$

- **標準誤差（SE）**：$SE = \frac{\sigma}{\sqrt{n}}$（標本平均の標準偏差）
- nが大きくなるほど標本平均のばらつきは小さくなる（$1/\sqrt{n}$ に比例して減少）

**標準偏差と標準誤差の違い**
- 標準偏差：個々のデータのばらつき
- 標準誤差：標本平均のばらつき（より小さい）

### 中心極限定理（CLT）

**定理**：母集団分布の形に関わらず、標本サイズ n が十分大きいとき：

$$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1) \quad (n \to \infty)$$

つまり、標本平均 $\bar{X}$ は近似的に $N(\mu, \sigma^2/n)$ に従う。

**「十分大きい」の目安**：n ≥ 30（統計検定2級では経験則でOK）

**実務的意味**：母集団が正規分布でなくても（例：歪んだ分布）、nが大きければ推測統計の手法が使える。

## 4-3 推定に使う分布の選択（最重要）

| 条件 | 使う分布 | 検定統計量 |
|------|---------|-----------|
| 母分散 σ² **既知** | 正規分布 $N(0,1)$ | $z = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$ |
| 母分散 σ² **未知**（n < 30） | t分布 $t(n-1)$ | $t = \frac{\bar{X}-\mu_0}{s/\sqrt{n}}$ |
| 母分散 σ² **未知**（n ≥ 30） | 正規分布で近似可 | $z \approx \frac{\bar{X}-\mu_0}{s/\sqrt{n}}$ |

### t分布の特徴

- 正規分布より裾が厚い（外れ値が出やすい）
- 自由度が増えると正規分布に近づく（自由度∞で標準正規分布に一致）
- 自由度 = n − 1

**判断フロー**

```
母分散は既知か？
  YES → 正規分布を使う（z検定）
  NO  → nは30以上か？
    YES → 正規分布で近似できる（z検定）
    NO  → t分布を使う（t検定）
```

## 4-4 区間推定（母平均）

### 点推定と区間推定

- **点推定**：母数を1つの値で推定（例：$\hat{\mu} = \bar{x} = 65$）
- **区間推定**：母数を含む確率が高い区間を推定

### 信頼区間の構造

$$\bar{X} \pm (\text{臨界値}) \times \frac{\text{標準偏差}}{\sqrt{n}}$$

### 母分散既知の場合（正規分布）

$$\bar{X} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$$

| 信頼係数 | $\alpha$ | $z_{\alpha/2}$ |
|---------|---------|---------------|
| 90% | 0.10 | 1.645 |
| 95% | 0.05 | **1.96** |
| 99% | 0.01 | **2.576** |

### 母分散未知の場合（t分布）

$$\bar{X} \pm t_{\alpha/2,\,n-1} \frac{s}{\sqrt{n}}$$

$t_{\alpha/2,\,n-1}$：自由度 $n-1$ の t分布の上側 $\alpha/2$ 点（分布表から読む）

### 計算例（母分散既知）

n=25、$\bar{x}=52$、σ=10、信頼係数95%のとき：

$$52 \pm 1.96 \times \frac{10}{\sqrt{25}} = 52 \pm 1.96 \times 2 = 52 \pm 3.92$$

→ **95%信頼区間：[48.08, 55.92]**

### 計算例（母分散未知）

n=16、$\bar{x}=50$、s=8、信頼係数95%のとき（$t_{0.025,15} = 2.131$ とする）：

$$50 \pm 2.131 \times \frac{8}{\sqrt{16}} = 50 \pm 2.131 \times 2 = 50 \pm 4.262$$

→ **95%信頼区間：[45.74, 54.26]**

### 信頼区間の正しい解釈（頻出の誤答対策）

**正しい解釈**：同じ方法でサンプリングを繰り返すと、その95%の区間が母平均を含む。

**誤った解釈**：「母平均がこの区間に入る確率が95%」（母平均は固定値なので確率は0か1）

### 信頼区間の幅に影響する要因

$$\text{幅} = 2 \times z_{\alpha/2} \times \frac{\sigma}{\sqrt{n}}$$

- **n を増やす** → 幅が狭くなる（精度が上がる）
- **信頼係数を下げる** → 幅が狭くなる（確実性が下がる）
- **σ が大きい** → 幅が広くなる

## 4-5 仮説検定の基本構造

### 5ステップの手順

1. **帰無仮説 H₀** を立てる：「差がない」「効果がない」の仮説
2. **対立仮説 H₁** を立てる：検証したい主張
3. **有意水準 α** を設定（通常0.05または0.01）
4. **検定統計量**を計算（z値またはt値）
5. **臨界値またはp値**と比較して結論する

### 片側検定と両側検定

| 対立仮説 | 検定の種類 | 棄却域 |
|---------|---------|-------|
| H₁: μ ≠ μ₀ | 両側検定 | $\|z\| > z_{\alpha/2}$ |
| H₁: μ > μ₀ | 右側（上側）検定 | $z > z_{\alpha}$ |
| H₁: μ < μ₀ | 左側（下側）検定 | $z < -z_{\alpha}$ |

**どちらを使うか**：研究者が「方向まで予想している」なら片側、「差があるかどうかを見る」なら両側を使う。

## 4-6 母平均の検定

### z検定（σ既知）

$$z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$$

### t検定（σ未知）

$$t = \frac{\bar{X} - \mu_0}{s/\sqrt{n}}$$

自由度：n − 1

**計算例（z検定）**

σ=10、n=25、$\bar{x}=52$、H₀: μ=50、H₁: μ≠50、α=0.05

$$z = \frac{52-50}{10/\sqrt{25}} = \frac{2}{2} = 1$$

$|z| = 1 < 1.96$ → **H₀は棄却されない**（有意差なし）

**計算例（t検定）**

s=4、n=20、$\bar{x}=72$、H₀: μ=70、H₁: μ≠70、α=0.05

$$t = \frac{72-70}{4/\sqrt{20}} = \frac{2}{4/4.47} = \frac{2 \times 4.47}{4} \approx 2.24$$

自由度19の $t_{0.025,19} = 2.093$ として：
$|t| = 2.24 > 2.093$ → **H₀を棄却**（有意水準5%で有意差あり）

## 4-7 有意水準・p値・検定の誤り

### 有意水準 α

帰無仮説が**正しいのに**棄却してしまう確率の上限。（第1種の誤りを犯す確率の許容上限）

### 検定の2種類の誤り

| | H₀が真 | H₀が偽 |
|--|---------|---------|
| **H₀を棄却** | **第1種の誤り（確率 = α）** | 正しい判断（検出力 = 1−β） |
| **H₀を棄却しない** | 正しい判断 | **第2種の誤り（確率 = β）** |

- **第1種の誤り（Type I Error）**：本当は差がないのに「差がある」と判断 → 有意水準 α で上限を設定
- **第2種の誤り（Type II Error）**：本当は差があるのに「差がない」と判断
- **検出力（Power）**：1 − β（差があるときに正しく検出できる確率）

**重要な関係**：α を小さくすると β が大きくなる（トレードオフ）。n を大きくすると両方を改善できる。

### p値の正確な意味

p値 = 帰無仮説が真であると仮定したとき、観測データ以上に極端な検定統計量が得られる確率

- p値 < α：稀な結果 → H₀のもとでは起こりにくい → H₀を棄却
- p値 ≥ α：H₀のもとでも十分ありえる → H₀を棄却しない

**陥りやすい間違い**
- p値は「H₀が正しい確率」ではない
- 「有意でない = H₀が正しい」ではない
- 「有意 = 実質的に意味がある差」ではない（nが大きければ小さな差も有意になる）

## 4-8 母比率の推定と検定

母比率（例：製品の不良品率、支持率）を扱う場合。

### 標本比率

$$\hat{p} = \frac{\text{成功数}}{n}$$

nが大きいとき、$\hat{p}$ は近似的に $N\left(p, \frac{p(1-p)}{n}\right)$ に従う。

### 母比率の95%信頼区間

$$\hat{p} \pm 1.96\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

### 母比率の検定

$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$$

**計算例**
n=200、成功数24（$\hat{p}=0.12$）、H₀: p=0.10、H₁: p≠0.10、α=0.05

$$z = \frac{0.12-0.10}{\sqrt{0.10 \times 0.90/200}} = \frac{0.02}{0.0212} \approx 0.943$$

$|z| = 0.943 < 1.96$ → 棄却されない
