### Category 1.8.

所得など経済的な量の集中度あるいは格差を表すためのグラフとしてアメリカの官庁統計家 M.O. ローレンツが考案した, **ローレンツ曲線**(*Lorenz curve*)がある. 一般に, ローレンツ曲線は正方形の中に描く. 
ここで原点$(0, 0)$から終点$(1, 1)$を通る45度線を描くと, これは$(0, 0), (0, 1), (1, 0), (1, 1)$の4点を頂点とする正方形の対角線となり, この直線を**完全平等線**(*complete equality line*)とよぶ. 
所得などが完全に均等分配されているならばローレンツ曲線は完全平等線と一致し, 不均等であればあるほどグラフは下に弧を描き, 直線から遠ざかる. 

ローレンツ曲線は分配の不平等さを示すグラフであるが, 不平等さを数値として表したものが**ジニ係数**(*Gini's coefficient*)である. ジニ係数はローレンツ曲線の正方形に対し, 完全平等線と弧の形で描かれたグラフで囲まれた図形の面積の割合の2倍で定義する. 不平等の程度を$[0, 1]$の値として表すことができ, その値により地域や年代間の比較ができるようになる. つまり, 0に近いほど平等で1に近いほど不平等という判断になる. 
:::note info
※ ジニ係数が同じでも, 対応するローレンツ曲線は複数存在することに注意
:::

### Category 1.9.

時系列データでは周期を扱うので, 同じ時系列の時点をずらした時系列との相関関係が重要となる. そこで, 相関係数と同じように時点差での相関関係を考える. 時系列データについて, もとの時系列$\{y_t, t = 1, 2, ... , T\}$と時点を$h$だけずらした時系列$\{y_{t+h}, t = 1, 2, ... , T - h\}$を別の変数のデータのように考えて2変数間の相関係数を求め, それを$h$の関数とみなしたものを**自己相関関数**(*autocorrelation function*)とよぶ. ここで*h*は**ラグ**(*lag*)とよばれ, 時間の遅れ, あるいは隔たりの大きさを表す. 時系列解析の分野では**自己共分散関数**(*autocovariance function*)を
```math
C_h = \frac{1}{T} \sum^{T - h}_{t = 1}(y_t - \bar{y})(y_{t+h} - \bar{y}), \qquad h = 0, 1, 2, ...
```
で計算し, それを用いて自己相関係数を
```math
r_h = \frac{C_h}{C_0}
```
により求めることが多い. 横軸にラグ$h$をとり, $r_h$を縦軸に示したグラフを**コレログラム**(*correlogram*)とよぶ.

### Category 5.4.

**問題**
> ある選挙において100人の投票者に出口調査を行ったところ, A候補に投票した人は54人であった. 
> 出口調査は単純無作為抽出に基づくとし, 二項分布は近似的に正規分布に従うとする. 
> A候補の真の得票率を$p$, A候補の標本得票率を表す確率変数を$\hat{p}$とするとき, $P(|\hat{p} - p| \leq 0.1)$の近似値を求めよ. 

**解答**
標本比率を$\hat{p}$, 標本サイズを$n$とする. $n$が十分大きいとき, $\hat{p}$の分布は平均$p$, 分散$\frac{p(1 - p)}{n}$の正規分布で近似できる. 
これより標本誤差の推定値は
```math
\hat{p} = \frac{54}{100} = 0.54, \qquad \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} = \sqrt{\frac{0.54 \times 0.46}{100}} = \sqrt{0.002484} \fallingdotseq 0.04983
```
となるので, 求める確率は
```math
P(|\hat{p} - p| \leq 0.1) = P\left( \frac{|\hat{p} - p|}{\sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}}  \leq \frac{0.1}{0.04983} \right) = P(|Z| \leq 2.0068) \fallingdotseq P(|Z| \leq 2.01)
```
と書ける. ここで$Z$は標準正規分布に従う確率変数である. あとは標準正規分布の上側確率より, 
```math
P(|Z| \leq 2.01) = 1 - 2 \times P(|Z| > 2.01) = 1 - 2 \times 0.0222 = 0.9556
```
を得る.

### Category 5.6.

**歪度**(*skewness*)
データの大きさ$n$の観測値$x_1, x_2, ..., x_n$から3次モーメント
```math
m_3 = \frac{1}{n}\sum^{n}_{i = 1}(x_i - \bar{x})^3
```
を求め, 以下の式で標本歪度を計算する. 
```math
標本歪度 = \frac{m_3}{s^3}.
```
ここで$s$は標本標準偏差である. 正規分布や自由度$\nu(>3)$の$t$分布のような左右対称の分布では歪度は0になり, 右に裾が長い分布では正の値に, 左に長い分布では負の値になる.

**尖度**(*kurtosis*)
データの大きさ$n$の観測値$x_1, x_2, ..., x_n$から4次モーメント
```math
m_4 = \frac{1}{n}\sum^{n}_{i = 1}(x_i - \bar{x})^4
```
を求め, 以下の式で標本尖度を計算する. 
```math
標本尖度 = \frac{m_4}{s^4} - 3.
```
正規分布に従う時は尖度は0になる. 正規分布と比較して, 尖っていて裾の長い分布の尖度は正の値となり, 逆に中心部が平坦で裾が短いとき負の値となる. $t$分布は自由度が大きいほど尖度は0に近づき, 歪度も0であることから正規分布に近づくことになる. 
:::note info
※ 尖度の定義として式の最後の3を引く定義と引かない定義がある.
:::

### Category 6.6.

**問題**
> 3つの試験科目の得点についてそれぞれ標準化したものを$X_1, X_2, X_3$とし, それらの平均を$Y = (X_1 + X_2 + X_3)/3$とする. 
> $X_1$と$X_2$の相関係数, $X_2$と$X_3$の相関係数, $X_3$と$X_1$の相関係数がいずれも0.5であるとき, $X_1$と$Y$の相関係数はいくらか.

**解答**
一般に確率変数$X, Y, Z$に対して以下が成り立つ. 
```math
\begin{align*}
V[X + Y] &= E[(X + Y - E[X + Y])^2] \\
&= E[X^2 - 2XE[X] + E[X^2] + Y^2 - 2YE[Y] + E[Y^2] + 2E[(X - E[X])(Y - E[Y])]]\\
&= E[(X - E[X])^2] + E[(Y - E[Y])^2] + 2E[(X - E[X])(Y - E[Y])]\\
&= V[X] + V[Y] + 2Cov[X, Y]. \\
Cov[X + Y, Z] &= E[(X + Y - E[X + Y])(Z - E[Z])] \\
&= E[(X - E[X] + Y - E[Y])(Z - E[Z])] \\
&= E[(X - E[X])(Z - E[Z])] + E[(Y - E[Y])(Z - E[Z])] \\
&= Cov[X, Z] + Cov[Y, Z].
\end{align*}
```
また, $X_1, X_2, X_3$は標準化されているので, いずれも平均$0$, 分散$1$の標準正規分布に従う.
よって相関係数が$0.5$であることから
```math
\rho[X_1, X_2] = \frac{Cov[X_1, X_2]}{\sqrt{V[X_1]}\sqrt{V[X_2]}} = Cov[X_1, X_2] = 0.5, \\
\rho[X_2, X_3] = \frac{Cov[X_2, X_3]}{\sqrt{V[X_2]}\sqrt{V[X_3]}} = Cov[X_2, X_3] = 0.5, \\
\rho[X_3, X_1] = \frac{Cov[X_3, X_1]}{\sqrt{V[X_3]}\sqrt{V[X_1]}} = Cov[X_3, X_1] = 0.5 \\
```
が成り立つ.これより$Y$の分散, $X_1$と$Y$の共分散は
```math
\begin{align*}
V[Y] &= V[(X_1 + X_2 + X_3)/3] = \frac{1}{9}V[X_1 + X_2 + X_3] \\
&= \frac{1}{9} \left( V[X_1 + X_2] + V[X_3] + 2Cov[X_1 + X_2, X_3] \right) \\
&= \frac{1}{9} \left( V[X_1] + V[X_2] + 2Cov[X_1, X_2] + V[X_3] + 2Cov[X_1, X_2] + 2Cov[X_2, X_3] \right) \\
&=  \frac{1}{9} \left( 1 + 1 + 2 \times 0.5 + 1 + 2 \times 0.5 + 2 \times 0.5 \right) \\
&= \frac{2}{3}. \\
Cov[X_1, Y] &= Cov[X_1, (X_1 + X_2 + X_3)/3] = \frac{1}{3}Cov[X_1, X_1 + X_2 + X_3] \\
&= \frac{1}{3}\left( Cov[X_1, X_1 + X_2] + Cov[X_1, X_3] \right) \\
&= \frac{1}{3}\left( Cov[X_1, X_1] + Cov[X_1, X_2] + Cov[X_1, X_3] \right) \\
&= \frac{1}{3}\left( 1 + 0.5 + 0.5 \right) \\
&= \frac{2}{3}.
\end{align*}
```
となる. 以上より$X_1$と$Y$の相関係数は
```math
\rho[X_1, Y] = \frac{Cov[X_1, Y]}{\sqrt{V[X_1]}\sqrt{V[Y]}} = \dfrac{\dfrac{2}{3}}{1 \times \sqrt{\dfrac{2}{3}}} = \frac{\sqrt{2}}{\sqrt{3}} = 0.81639 \cdots .
```

### Category 6.8.

**問題**
> 確率変数$Z_1, Z_2, Z_3, Z_4, Z_5, Z_6$は互いに独立に標準正規分布に従うとする. 
> $\qquad T = Z_2^2 + Z_3^2 + Z_4^2 + Z_5^2 + Z_6^2, \qquad V = Z_1 / \sqrt{T/5}, \qquad W = (T / 5) / Z_1^2$
> と置いたとき, $P(W \leq \alpha) = 0.05$となる実数$\alpha$を求めよ.

**解答**
確率変数$Z_2, Z_3, Z_4, Z_5, Z_6$はいずれも独立なので, $T$は自由度$5$の$\chi^2$分布に従う.
さらに$Z_1$と$T$は独立であるので, $V$は自由度$5$の$t$分布に従い, $W$は自由度$(5, 1)$の$F$分布に従う. 
ここで求める実数は, $W = 1 / V^2$であることから
```math
P(W \leq \alpha) = P \left( \frac{1}{V^2} \leq \alpha \right) = P \left( |V| \geq \frac{1}{\sqrt{\alpha}} \right) = 0.05
```
を満たす. 今$V$は自由度$5$の$t$分布に従うので, $|V|$であることに注意すると$P(V \geq 2.571) = 0.025$となるような$\alpha$であればよい. よって
```math
\frac{1}{\sqrt{\alpha}} = 2.571, \qquad \therefore \alpha = 0.15128 \cdots .
```

### Category 7.3.

**問題**
> 10万人以上の有権者がいる都市がある. 有権者を対象とする単純無作為抽出による標本調査で, ある政策の支持率を区間推定したい.
> 信頼係数95%の信頼区間の幅が6%以下となるようにするには, 少なくとも何人以上の有権者を調査すればよいだろうか.
> ただし調査された人は必ず支持または不支持のいずれかを回答するものとし, 二項分布は近似的に正規分布に従うとする.

**解答**
調査する有権者数を$n$とする. 推定したい支持率を$\hat{p}$とおくと, 母集団が十分大きいので$\hat{p}$は近似的に平均$p$, 分散$\frac{p(1 - p)}{n}$の正規分布に従う. ただし真の支持率を$p$とおいた.
よって信頼係数95%の信頼区間の幅が6%以下より
```math
\frac{|\hat{p} - p|}{\sqrt{\frac{p(1 - p)}{n}}} \leq 1.96 \Leftrightarrow \hat{p} - 1.96 \times \sqrt{\frac{p(1 - p)}{n}} \leq p \leq \hat{p} + 1.96 \times \sqrt{\frac{p(1 - p)}{n}} \\
\therefore 2 \times 1.96 \times \sqrt{\frac{p(1 - p)}{n}} \leq 0.06
```
が常に成り立つような$n$ならよい. ここで
```math
p(1 - p) \leq \frac{1}{2} \times \left(1 - \frac{1}{2} \right) = \frac{1}{4} \qquad \left( 等号成立はp = \frac{1}{2}のとき \right)
```
であるので, 求める$n$は
```math
2 \times 1.96 \times \sqrt{\frac{p(1 - p)}{n}} \leq 2 \times 1.96 \times \sqrt{\frac{1}{4n}} \leq 0.06 \\
\therefore 2 \times 1.96 \times \sqrt{\frac{1}{4n}} \leq 0.06 \\
\therefore n \geq \left( \frac{1.96}{0.06} \right)^2 \\
\therefore n \geq 1067.06 \cdots .
```

### Category 7.5.

母集団の分布が正規分布ではないとき, 母平均$\mu$の信頼区間はどのように設定すべきだろうか.
この非正規母集団から無作為抽出した大きさ$n$の標本の標本平均を$\bar{X}$, 不変分散を$S^2$とおき, 統計量を$Z = \frac{\bar{X} - \mu}{\sqrt{S^2 / n}}$とする.

正規母集団からの無作為抽出であれば$Z$の分布は自由度$n - 1$の$t$分布に従うが, 非正規母集団の場合は$Z$の分布は標本の大きさ$n$および母集団分布に依存する.標本の大きさ$n$が十分小さい場合は$Z$は母集団分布に依存し, 十分大きい場合は中心極限定理から$Z$の分布は標準正規分布で近似できる.

資料 : 文部科学省「体力・スポーツに関する世論調査（平成25年1月調査）」

> 上記の表は平成25年1月に行われた, スポーツ国際大会での日本人選手の活躍にどのくらい関心を持っているか調査をした結果である(回答総数 1897人).
> 平成21年9月に行われた同調査において「非常に関心がある」とする者の割合は41.6%(回答総数1925人)であったが, 「非常に関心がある」と回答した人の割合は増加したと言えるだろうか. 有意水準5%で検定を行い, 評価せよ.

**解答**
上記の2調査における, 「非常に関心がある」と回答した人の割合の差が$0$であると言えるかどうかを考える.
母比率の差の信頼係数95%の信頼区間は
```math
P \left( \frac{|\hat{p} - (p_1 - p_2)|}{\sqrt{\dfrac{p_1(1 - p_1)}{n_1} + \dfrac{p_2(1 - p_2)}{n_2}}} \leq 1.96 \right) = 0.025
```
を満たすような$\hat{p}$の区間であるので, これより
```math
p_1 - p_2 - 1.96 \times \sqrt{\frac{p_1(1 - p_1)}{n_1} + \frac{p_2(1 - p_2)}{n_2}} \leq \hat{p} \leq p_1 - p_2 + 1.96 \times \sqrt{\frac{p_1(1 - p_1)}{n_1} + \frac{p_2(1 - p_2)}{n_2}}
```
なる区間が求める信頼区間である. ここで
```math
p_1 = 0.483, \quad p_2 = 0.416, \quad n_1 = 1897, \quad n_2 = 1925
```
を代入すると
```math
0.067 \pm 1.96 \times \sqrt{\frac{0.483 \times 0.517}{1897} + \frac{0.416 \times 0.584}{1925}} \\
\therefore 0.067 \pm 1.96 \times \sqrt{0.00013163 + 0.0001262} \\
\therefore 0.067 \pm 1.96 \times 0.0161 \\
\therefore [0.035444, 0.098471]
```
を得る.この95%信頼区間は$0$を含まないため, 有意水準5%で2つの割合の差は$0$ではないと言える.

が成り立つ. これは上側確率$0.025$では棄却されないが, $0.05$では棄却されることを意味している.

### Category 8.5.

**問題**
> あるメーカーA社では製品の不良品率が5%であるというが, この割合が実際に正しいかどうかを確認するため試しにA社に試作品を200個作成してもらい, 実際の製品における不良品率を検査することにした.
> 作成してもらった200個の試作品のうち不良品の個数が16個であったとき,不良品率を$r$として帰無仮説$r = 0.05$, 対立仮設$r > 0.05$の検定を行う場合の$P$-値を求めよ.

**解答**
標本の不良品率を$\hat{r}$とおくと, 
```math
\hat{r} = \frac{16}{200} = 0.08
```
である.これより検定統計量$Z$を計算すると
```math
z = \frac{\hat{r} - r}{\sqrt{\dfrac{r(1 - r)}{n}}} = \frac{0.08 - 0.05}{\sqrt{\dfrac{0.05 \times 0.95}{200}}} = \frac{0.03}{0.01541} = 1.9467 \cdots
```
となる. ここで$Z$が近似的に標準正規分布に従うことより
```math
P(|Z| \geq 1.9467) = 0.0262
```
を得る.

> 各リーグ内にて入場者数は独立で同一の分布に従い, かつセントラル・リーグとパシフィック・リーグの各球団の年間入場者数の母分散は等しいとみなし, 両リーグの球団別年間入場者数の母平均に差があるかどうかを検定したい. このときの$t$値はいくらになるだろうか.

**解答**
母集団が未知で等しい場合の母平均の差の検定における$t$統計量の計算式は
```math
t = \frac{\bar{x} - \bar{y}}{\sqrt{\left( \dfrac{1}{m} + \dfrac{1}{n} \right) \times \dfrac{\sum (x_i - \bar{x})^2 + \sum (y_j - \bar{y})^2}{m + n - 2}}}
```
で与えられる. ただし$x_1, x_2, ... , x_m, y_1, y_2, ... , y_n$は無作為に抽出した標本であり, $m, n$はそれぞれ$X, Y$の自由度である.これより求める$t$値は
```math
t = \frac{233.7 - 185.3}{\sqrt{\left( \dfrac{1}{6} + \dfrac{1}{6} \right) \times \dfrac{13549 + 7763}{6 + 6 - 2}}} = \frac{48.4}{\sqrt{710.4}} = \frac{48.4}{26.6533} = 1.8159 \cdots
```
となる.

### Category 8.8.

**問題**
> あるメーカーA社とB社ではどちらも製品の不良品率が5%であるというが, この割合が実際に正しいかどうかを確認するため試しに両社に試作品を200個作成してもらい, 実際の製品における不良品率を検査することにした.
> 作成してもらった200個の試作品のうち不良品の個数がA社では16個, B社では17個であったとき,両社の不良品率の差を$d$として帰無仮説$d = 0$, 対立仮設$d > 0$の検定を行う場合の$P$-値を求めよ.

**解答**
A社, B社の不良品率をそれぞれ$r_A, r_B$, 標本サイズを$n_A, n_B$とする. このとき母集団の日に関する帰無仮説$d = 0$, 対立仮設$d > 0$の仮設検定を行う場合, 通常用いる検定統計量は
```math
Z = \dfrac{\hat{r_A} - \hat{r_B}}{\sqrt{\dfrac{\hat{r_A}(1 - \hat{r_A})}{n_A} + \dfrac{\hat{r_B}(1 - \hat{r_B})}{n_B}}}
```
である. この値を求めると
```math
z = \dfrac{0.08 - 0.085}{\sqrt{\dfrac{0.08 \times 0.92}{200} + \dfrac{0.085 \times 0.915}{200}}} = \dfrac{-0.005}{\sqrt{0.000368 + 0.000388875}} = \dfrac{-0.005}{0.027511} = 0.18174 \cdots
```
となる. これより$P$値は
```math
P(|Z| \geq |z|) = 2 \times P(Z \geq 0.1817) = 2 \times 0.4286 = 0.8572.
```
