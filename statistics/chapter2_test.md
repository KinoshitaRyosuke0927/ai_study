# 解答・解説

---

## 主要問題の解説

### 問題1
4の倍数：4, 8, 12 → 3個 → P = 3/12 = **1/4 → B**

### 問題2
P(A∪B) = 0.6 + 0.5 − 0.3 = **0.8 → C**

### 問題4
排反 = $A \cap B = \emptyset$（積事象が空集合）→ **B**
AとBが確率 > 0 なら排反は独立にならない。確率の和が1になるとは限らない。

### 問題6
P(A)P(B) = 0.5 × 0.4 = 0.20 = P(A∩B) → **独立 → B**

### 問題7
$\binom{3}{2}(1/2)^2(1/2)^1 = 3/8$ **→ C**

### 問題8
$P(\text{不良}) = 0.03 \times 0.7 + 0.07 \times 0.3 = 0.021 + 0.021 = 0.042$ **→ B**

### 問題9（ベイズ）
$P(A|\text{不良}) = \frac{0.03 \times 0.7}{0.042} = \frac{0.021}{0.042} = 0.500$ **→ B**

### 問題10（ベイズ）
$P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{0.6 \times 0.4}{0.3} = \frac{0.24}{0.3} = 0.80$ **→ D**

### 問題14
$A^c = \{1,3,5\}$、$B^c = \{4,5,6\}$
$A^c \cap B^c = \{5\}$（DeMarganの定理より $(A \cup B)^c$）
$A \cup B = \{1,2,3,4,6\}$ → $(A \cup B)^c = \{5\}$
P = 1/6 **→ A**

### 問題15
$P(D) = 0.01$、$P(+|D) = 0.95$、$P(+|D^c) = 0.10$

$P(+) = 0.95 \times 0.01 + 0.10 \times 0.99 = 0.0095 + 0.099 = 0.1085$

$P(D|+) = 0.0095/0.1085 \approx 0.0876 \approx$ **8.7% → A**

有病率が低いと、高感度の検査でも偽陽性が多くなる。
