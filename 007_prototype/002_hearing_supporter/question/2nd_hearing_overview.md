# 第2回ヒアリングに向けた資料（たたき）

## 第2回の目的

第1回の内容をもとに、**メンバーの業務の中にある課題を具体化する**。
作業の流れに加えて、頻度、時間、記録の有無といった具体的な情報を聞きたい。
当日に解決策を決めることはしない。あくまで具体的な情報収集が目的。

## 第1回からの変更点

| | 第1回 | 第2回 |
|---|---|---|
| 聞く内容 | 普段の1日の流れ、平均的な業務内容 | 直近の具体的な作業内容 |
| 聞き方の例 | 「普段はどのように進めていますか？」 | 「先週の○○は、どのように進めましたか？」 |
| 目的 | 業務の全体像を知る | 課題の場面や原因、大きさ、頻度を具体的に知る |

## 深掘りしたい課題の仮説

### 砂盃さん

**仮説1：並行案件の時間の使い方と、進み具合の把握**

3つの案件が並行していて、日々時間の使い方に悩んでいる。特に、作業の進み具合の把握が感覚的になっている。また、調査や打ち合わせで一日が埋まり、考える時間を十分に取れていない可能性がある。

お聞きしたいことの例：

- 先週、予定どおりに進まなかった日の流れ
- 遅れに気づいたタイミングと、そのきっかけ
- 直近の企画書で、相談するタイミングを決めた判断材料
- 案件ごとの予定や実際にかかった時間の記録の有無
- 先週、まとまって考える時間をどのくらい取れたか
- 新規企画が想定より遅れた要因
- 集中しやすい時間帯と、そのときの作業

**仮説2：毎週の定例会に向けた準備**

毎週の定例会に向けて、スケジュール調整や資料の準備が発生している。あわせて、定例会が参加人数に見合う場になっているかも確認したい。

お聞きしたいことの例：

- 直近の定例会に向けて、ご自身で行った準備の順番と合計時間
- 特に時間がかかった工程
- 資料や情報が揃わなかったときの対応
- 定例会で決まったことや宿題の記録と、進み具合の確認方法
- 結論が持ち越された議題や、発言がなかった参加者の有無

### 石井さん

**仮説1：石井さんに集中している作業**

ご本人は大きな負担と感じていないかもしれないが、石井さんでないと進めにくい作業がある。

お聞きしたいことの例：

- 直近の朝の確認で見た項目、順番、所要時間
- 最近対応が必要になった例と、気づいたきっかけ
- 直近で、ご自身でないと進めにくかった作業とその理由
- 確認に使うログや指標、過去の対応の記録の有無

**仮説2：頭の中で考えている内容の多さ**

頭の中で考えている内容が多く、複数人で進めるとかえってややこしくなる作業を、一人で進めている。

お聞きしたいことの例：

- 直近で加藤さんに作業を渡したときの流れと、渡した形式
- 渡した後の確認のやり取りや、手戻りの有無
- 見積もりが大きくずれた直近の例
- 考えた内容が文書やチケットに残る範囲
- 作業の終了時期を聞かれたときの答え方

**補足：朝会や打ち合わせなどの場の負担**

朝会や打ち合わせが負担になっていて、場の目的に対して参加者や時間が合っていない可能性がある。

お聞きしたいことの例：

- 先週、負担が大きかった場
- その場の目的に対して、参加者や時間が合っていたか

## もし手に入ればモデル作成に使えそうな情報

| 情報 | 例 |
|---|---|
| 頻度 | 週に何回、月に何件発生するか |
| 時間 | 1回あたりに何分、何時間かかるか |
| 判断の材料 | 何を見て、どう判断しているか |
| 記録の有無 | 予定と実績、進捗、ログ、履歴はどこに残っているか |
| 記録の形式と量 | どの形式で、どのくらい前の分まであるか |
| 結果の記録 | 判断や対応の結果まで残っているか |

## 当日の進め方

- 聞き手は2人で、質問役1人、記録と時間管理1人に分かれる。
- 内容から優先度を**◎は必ず聞く質問、○は時間があれば聞く質問**とした。読み上げず、話の流れに合わせて順番を変えることも想定。
- 「普段は」ではなく、「先週は」「直近の○○では」と具体的な場面を聞く。
- その場で解決策の提案やAIで実現できるかどうかの回答はしない。
