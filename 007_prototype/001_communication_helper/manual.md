# コミュニケーション練習ツール 利用手順

AIが演じる会話相手（新入社員の「鈴木さん」）と音声で会話しながら、コミュニケーションを練習できるアプリケーションです。
あなたの言葉遣いや話し方によって、鈴木さんの気持ちがどう変化したかを、会話中にグラフと表情で確認できます。
会話の終了後には、良かったところ・改善できるところをまとめた振り返りレポートが表示されます。

## 1. フォルダ構成

配布フォルダには以下が含まれています。

```
communication_helper/
├── communication_helper.exe   ... アプリ本体
├── 起動.bat                    ... ダブルクリックで起動＆ブラウザを開くショートカット
├── .env                        ... Azure OpenAI の接続情報とアプリの設定
├── manual.md                   ... 本ファイル
└── _internal/                  ... アプリ動作用の内部ファイル（画面・表情画像など。触らないでください）
```

## 2. 事前準備

このアプリは追加のソフトウェアインストールは不要です。ただし、利用開始前に以下を確認してください。

### 2-1. `.env` の設定

`communication_helper.exe` と同じフォルダの `.env` に、以下の接続情報と設定が記載されている必要があります。

```
AZURE_OPENAI_ENDPOINT=https://your-resource.services.ai.azure.com/openai/v1
AZURE_OPENAI_KEY=your-api-key
AZURE_REALTIME_DEPLOYMENT=gpt-realtime-mini
AZURE_TRANSCRIBE_MODEL=gpt-transcribe
AZURE_EVAL_DEPLOYMENT=gpt-5.4-mini
SESSION_MAX_MINUTES=10
PROACTIVE_SILENCE_SEC=8
```

- Azure OpenAI の接続情報（`AZURE_` で始まる項目）は配布時に設定済みのため、変更不要です。
- `.env` には API キーが含まれています。ほかの人に渡したり、共有フォルダに置いたりしないでください。

以下の2項目は、必要に応じて自分で変更できます。変更後はアプリを再起動すると反映されます。

| 項目 | 説明 |
|------|------|
| `SESSION_MAX_MINUTES` | 1回の会話の上限時間（分）。この時間に達すると会話が自動で終了します（初期値: 10） |
| `PROACTIVE_SILENCE_SEC` | 誰も話さない状態がこの秒数続くと、鈴木さんから話しかけてきます（初期値: 8） |

### 2-2. 利用環境

| 項目 | 内容 |
|------|------|
| ブラウザ | Google Chrome または Microsoft Edge（最新版） |
| マイク | PC 内蔵マイク、またはヘッドセットのマイク |
| スピーカー | **イヤホン・ヘッドセットを推奨**します。スピーカーを使うと、鈴木さんの声をマイクが拾い、あなたの発言として扱われることがあります |
| ネットワーク | インターネット接続が必要です（AI との通信、グラフの表示に使用します） |

## 3. アプリの起動方法

`起動.bat` をダブルクリックしてください。自動的にアプリが起動し、既定のブラウザで `http://localhost:8000` が開きます。

（`起動.bat` を使わず `communication_helper.exe` を直接ダブルクリックした場合は、手動でブラウザから `http://localhost:8000` にアクセスしてください。）

- アプリの起動より先にブラウザが開くため、最初に「このサイトにアクセスできません」と表示された場合は、数秒待ってからページを再読み込みしてください。
- 起動時に黒いコンソール画面が表示されますが、これはアプリのログ出力用の画面です。閉じるとアプリが終了するため、利用中は閉じないでください。

## 4. 使い方

画面は左・中央・右の3つのエリアに分かれています。

| エリア | 内容 |
|------|------|
| 左エリア | 会話相手・性別・シチュエーションの選択、「会話を開始」「終了」ボタン、会話の状態 |
| 中央エリア | 上から、鈴木さんの表情（Web会議の相手の映像のような表示）、会話相手とシチュエーションの説明、鈴木さんの気持ち（値と推移グラフ） |
| 右エリア | 会話ログ（あなたと鈴木さんの発言の文字起こし、あなたの発言への評価） |

### 4-1. 会話の準備

1. 左エリアのプルダウンで、以下を選択します。
   - **会話相手**: 新入社員 鈴木さん
   - **性別**: 女性 / 男性（鈴木さんの声と表情の画像が切り替わります）
   - **シチュエーション**: 練習したい場面を選びます

     | 分類 | シチュエーション | 内容 |
     |------|------|------|
     | 業務 | ミスを指摘する | 鈴木さんが実装した機能の不具合を、鈴木さんを呼んで指摘する |
     | 業務 | 急ぎの仕事を頼む | 別の作業をしている鈴木さんに、今日中の急ぎの作業をお願いする |
     | 業務 | 相談を受ける | 仕事の進め方に悩む鈴木さんから相談を受ける |
     | 雑談 | 昼休みの雑談 | 休憩室で鈴木さんと二人きりになり、仕事以外の話題で雑談する |
     | 雑談 | 帰りのエレベーター | 退勤時のエレベーターで、1階に着くまでの短い時間に会話する |
     | 雑談 | 週明けの雑談 | 月曜の朝に、週末の話題などで雑談する |

2. 中央エリアの説明欄で、選んだシチュエーションの状況を確認します。
   あなたと鈴木さんは、どちらも IT 企業で勤怠管理システム「KinTai Cloud」を開発するエンジニアという設定です。
   あなたは鈴木さんの先輩社員として会話します。

### 4-2. 会話する

1. 左エリアの「会話を開始」をクリックします。
   - 初回は、ブラウザからマイクの使用を許可するか確認されます。「許可する」を選んでください。
   - 画面上部の表示が「接続中（話しかけてください）」になり、会話ログに「会話を開始しました」と表示されたら、会話を始められます。
2. シチュエーションによっては、鈴木さんから話しかけてきます（ミスを指摘する・相談を受ける・帰りのエレベーター）。それ以外は、あなたから話しかけてください。
3. マイクに向かって、普段どおりに話してください。ボタン操作は不要です。
   - あなたが質問したり、依頼したり、話を振ったりすると、鈴木さんが返事をします。
   - 「〜なんだけど、」のように話の途中で区切ったときは、鈴木さんは「はい」などの相づちだけを返し、続きを待ちます。
   - 「えっと…」「うーん」と考えている間は、鈴木さんは黙って待ちます。
   - 誰も話さない状態が続くと（初期値 8 秒）、鈴木さんから話しかけてきます。
   - 鈴木さんが話している途中にあなたが話し始めると、鈴木さんは話すのをやめます（「割り込み」として記録されます）。
4. 鈴木さんは、あなたの言葉遣いや話し方に応じて態度が変わります。
   高圧的な言い方をされると萎縮して口数が減り、配慮のある言い方をされると安心して自分から質問や相談をするようになります。
5. 会話は上限時間（初期値 10 分）に達すると、自動で終了します。

### 4-3. 画面の見方

**左エリア（会話の状態）**

| 表示 | 説明 |
|------|------|
| あなた / 相手 | 話している間、左の丸が赤く点灯します |
| 経過 | 会話の経過時間 / 上限時間 |
| 割り込み | 鈴木さんの発言の途中で話し始めた回数 |

**中央エリア（鈴木さんの表情と気持ち）**

- **表情**: 鈴木さんの気持ちに合わせて、表情の画像が切り替わります（穏やか・笑顔・考え込み・動揺・不満）。
  - 鈴木さんが話している間は、枠が緑色に光ります。
  - この表情のエリアをクリックすると、鈴木さんの声の **オン / オフ** を切り替えられます（右下に「🔊 音声オン」「🔇 音声オフ」と表示されます）。オフにしても、会話ログの表示や気持ちの推定は続きます。
- **鈴木さんの気持ち**: あなたが発言するたびに、AI が鈴木さんの気持ちを推定し、4つの値（0〜100）を更新します。
  推定には数秒かかり、その間は見出しの横に「推定中…」と表示されます。

  | 項目 | 意味 |
  |------|------|
  | 安心感 | この人の前なら失敗しても大丈夫、話しても大丈夫と思える度合い |
  | 緊張 | 怖い・萎縮している・言い出しにくいと感じている度合い（**低いほど良い状態**） |
  | 意欲 | 頑張ろう、話を続けたいと前向きになれている度合い |
  | 信頼感 | この人の言うことなら聞こう、ついていこうと思える度合い |

  - 値の右の「▲」「▼」は、直前の発言による変化量です。
  - 右側のグラフは、発言ごとの気持ちの推移です。グラフの点にカーソルを合わせると、そのときの発言と、気持ちが変化した理由が表示されます。

**右エリア（会話ログ）**

- あなたの発言は右側（青）、鈴木さんの発言は左側（グレー）に表示されます。鈴木さんの相づちは小さく表示されます。
- あなたの発言の下には、気持ちの推定が終わると以下が表示されます。
  - **声の特徴**（間・話速・声量・声の高さ・抑揚）: 印象に影響しそうな特徴はオレンジ色で強調されます。声量・声の高さは、それまでのあなたの発言との比較です（最初の発言では表示されません）
  - **○ 良かった点**（緑色）/ **△ 改善点**（赤色）
- 会話ログは常に最新の発言が見えるように自動でスクロールします。上にスクロールして過去の発言を見ている間は、位置を保ちます。

### 4-4. 会話の終了と振り返りレポート

1. 会話を終えるときは、左エリアの「終了」をクリックします。
2. 数秒後に「振り返りレポート」が表示されます（あなたの発言が1つもない場合は作成されません）。

   | 項目 | 内容 |
   |------|------|
   | 総評 | 会話全体の振り返り |
   | 鈴木さんの気持ちの変化 | 4つの気持ちの、会話開始時と終了時の値・変化量 |
   | 鈴木さんから見たあなた | 鈴木さんの本音としての、あなたの印象 |
   | 良かったところ | 良かった発言と、その理由 |
   | もっと良くできるところ | 改善したい発言と、どう伝わったか、言い換え例 |
   | 次回意識すること | 次の練習で意識するとよいこと |

3. 「閉じる」をクリックするか、レポートの外側をクリックするとレポートが閉じます。
   閉じた後も、左エリアの「振り返りレポートを見る」から再表示できます（次の会話を開始するまで）。
4. 「レポートダウンロード」をクリックすると、レポートと会話ログ（各発言への評価を含む）を Markdown 形式のファイル
   （`report_年月日_時分_シチュエーション名.md`）として保存できます。

会話の内容とレポートは、アプリには保存されません。ブラウザを閉じたり、次の会話を開始したりすると消えるため、残したい場合はダウンロードしてください。

### 4-5. 練習のコツ

- 同じシチュエーションで、言い方を変えて何度か練習してみてください。鈴木さんの気持ちの変化やレポートの内容を比べると、言い方による違いが分かりやすくなります。
- レポートの「言い換え例」を、次の練習で実際に使ってみてください。
- 気持ちの値や評価は AI による推定のため、同じ発言でも結果が多少変わることがあります。数値そのものより、変化の傾向や理由を参考にしてください。

## 5. アプリの終了方法

ブラウザのタブを閉じたうえで、起動中のコンソール画面を閉じるか、`Ctrl + C` を押してください。

## 6. トラブルシューティング

| 症状 | 原因・対処 |
|------|-----------|
| 起動直後にコンソールが閉じてしまう | `.env` が exe と同じフォルダに無い、または `AZURE_OPENAI_ENDPOINT` / `AZURE_OPENAI_KEY` が未設定です。2-1を確認してください。エラー内容を確認したい場合は、PowerShell 等で exe のフォルダに移動して `.\communication_helper.exe` を実行してください。 |
| ブラウザで画面が表示されない | コンソール画面にエラーが出ていないか確認し、`http://localhost:8000` に手動でアクセスしてください。8000 番ポートを使う別のアプリ（AIリマインダー等）が起動している場合は、そちらを終了してから再度お試しください。 |
| 「会話を開始」をクリックしても接続されない / マイクの許可を求められない | ブラウザでマイクがブロックされている可能性があります。アドレスバー左のアイコンからサイトの設定を開き、マイクを「許可」にしてページを再読み込みしてください。Windows の設定（プライバシーとセキュリティ → マイク）で、ブラウザのマイク利用が許可されているかも確認してください。 |
| 「接続に失敗しました」と表示される | インターネット接続、または Azure OpenAI との通信に問題がある可能性があります。ネットワークを確認して再度お試しください。改善しない場合は配布元に問い合わせてください（`.env` の接続情報が無効になっている可能性があります）。 |
| 「接続が切断されました」と表示される | 通信が途中で切れました。もう一度「会話を開始」をクリックしてください。 |
| 鈴木さんの声が聞こえない | 表情のエリア右下が「🔇 音声オフ」になっていないか確認してください（クリックでオンに戻ります）。PC の音量・出力先（イヤホン等）も確認してください。 |
| 話しても反応がない / 会話ログに「（聞き取れませんでした）」と表示される | マイクの音量が小さい、または別のマイクが選ばれている可能性があります。Windows のサウンド設定や、ブラウザのサイトの設定でマイクを確認してください。 |
| 自分が話していないのに、あなたの発言として文字が表示される | 鈴木さんの声をマイクが拾っている可能性があります。イヤホン・ヘッドセットを使用してください。 |
| 鈴木さんが返事をしない | 話の途中と判断され、続きを待っている可能性があります。質問や依頼の形で言い終えるか、しばらく待つと鈴木さんから話しかけてきます。 |
| 発言しても気持ちの値が更新されない | AI との通信が一時的に失敗した可能性があります。次の発言から再度推定されます。続く場合は会話をやり直してください。 |
| 「レポートを作成できませんでした」と表示される | AI との通信が一時的に失敗した可能性があります。会話をやり直してください。あなたの発言が1つもない場合もレポートは作成されません。 |
| グラフが表示されない | グラフの表示にはインターネット接続が必要です。ネットワークを確認してページを再読み込みしてください。 |
| 「上限時間に達したため終了しました」と表示される | 1回の会話の上限時間（初期値 10 分）に達しました。必要に応じて `.env` の `SESSION_MAX_MINUTES` を変更してください（2-1参照）。 |
