# AIコミュニケーション練習ツール 案

## アイデア概要

AIを相手に、会話・発表などのコミュニケーションを何度でも練習できるツール。

様々な人格・役割を持つAIエージェントとコミュニケーションを行い、  
ユーザの言動に対して「相手からどう見えたか」「何が良くなかったか」「どう改善できるか」をフィードバックする。


## 解決したい課題

コミュニケーション能力は、知識だけではなく実際に他者とやり取りする経験と  
フィードバックによって身につく部分が大きい。

一方で、コミュニケーションに苦手意識がある人ほど、

* 相手の立場・感情を考慮した会話が難しい
* 自分の言動が相手にどう受け取られているか分からない
* 社会・ビジネス上の適切な振る舞いを練習する機会が少ない
* 実際の人間を相手に失敗しながら練習することが難しい

といった課題がある。

そこで、失敗しても問題のないAIを練習相手にすることで、様々なコミュニケーションを繰り返し経験できる環境を作る。


## 想定ユーザ

社会・ビジネス上のコミュニケーションに課題を感じている成人

例：

* 会話や受け答えが苦手
* 相手の立場を考えて話すことが苦手
* ビジネスマナーに自信がない
* 人前での説明・発表が苦手
* コミュニケーションを練習する機会が欲しい


## 主要機能イメージ

1. 会話機能（優先：高）
- 人格・役割の異なるAIエージェントとリアルタイムで会話する。
    - 話題はユーザ側から指定することも、ランダムで設定することもできてほしい
- 会話内容に応じてAIの表情・感情が変化し、ユーザの発言に対するフィードバックを表示する。
    - 初期は、感情のわかりやすさ、作りやすさを重視して、喜怒哀楽とニュートラルの5種×感情の強度3段階程度の固定画像を表示するイメージ
    - +αとして、将来的にリアルタイムでリアルな顔（動画）での感情表現もできるとうれしい
- ユーザの期待：
    - マナーを学びたい
    - 言葉遣い、ボキャブラリーを増やしたい
    - 流行、ジェネレーションに応じた話題を知りたい
    - 雑談のセンスを磨きたい

2. 発表機能（優先：中）
- PowerPoint等の資料を表示しながら、AIエージェントを聴衆としてプレゼンテーションを行う。
- 発表終了後、「上司」「顧客」「同僚」など、それぞれの立場から内容や伝え方についてフィードバックする。
- ユーザの期待：
    - 伝わりやすい話し方を知りたい
    - 限られた時間で必要十分の話をしたい
    - 意図が正しく伝わっているか確認したい
    - どのような質問が来るか準備したい

3. AIエージェント作成機能（優先：中）
- ユーザの環境次第で、期待するエージェントの人格・役割が異なるはずなので、ある程度調整が出来るようにしたい
- 初期は用意されている人格から選択でもいい
    - 最優先でほしい人格は、来期の新入社員
- お手軽作成モード：
    - イメージ：アンケート、人格診断など
    - いくつかのカテゴリから、あてはまるものを選択していく形式で、エージェントの人格を設定する
        - 役職
        - 年齢
        - 性別
        - 趣味
        - など
    - ある程度汎化された人格との会話で十分な人向け
- 詳細作成モード：
    - イメージ：ユーザ自身がプロンプトエンジニアリングできる
    - 特定の人物の特徴、実際の会話の履歴、録音など、自由な入力形式でエージェントを作成できる
        - 会話形式の生成AIのサポートがあるといい
    - 特定の個人とのコミュニケーションを練習したい人向け

※画面イメージは、既存ミーティングツールのUIをイメージ。  
サイドにフィードバック等の本システム固有の要素が並ぶ感じ。



## 目指す体験

実践 → 相手の反応 → フィードバック → 振り返り → 再挑戦

を毎日小時間、繰り返すことで、ユーザ自身では気づきにくいコミュニケーション上の問題を発見し、改善につなげる。

単にAIと会話するのではなく、「相手にどう受け取られたか」を体験しながら学べることを重視する。

## コンセプト

失敗しても問題のないAI相手に、何度でもコミュニケーションを練習できる場所。
