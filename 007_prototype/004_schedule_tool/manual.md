# スケジュール確認ツール 利用手順(利用者向け)

GROUPSESSION のマイグループのメンバーの予定をまとめて取得し、全員が空いている時間帯や、日ごとの出社割合を確認できるアプリケーションです。

> 同じ内容を、画面つきでツールの中でも確認できます(画面右上の「使い方」ボタン)。
> ラベル付け・モデルの学習・配布など管理者向けの手順は README.md の「管理者向けの運用手順」を参照してください。

- **GROUPSESSION の予定は変更しません**(参照専用です)。
- 取得した予定は画面に表示するだけで、ファイルには保存しません。予定の内容をファイルに出力する機能もありません。
- 出社割合の判定は、このPCの中だけで行います(外部のサービスには送りません)。

## 1. フォルダ構成

```
schedule_tool/
├── schedule_tool.exe ... アプリ本体
├── config.json       ... 設定(初回起動時に自動で作られます)
├── data/             ... 出社割合の判定に使うファイル(office_model.joblib。消したり移動したりしないでください)
└── _internal/        ... アプリ動作用の内部ファイル(触らないでください)
```

## 2. 起動と終了

- `schedule_tool.exe` をダブルクリックすると、黒いコンソール画面が開き、ブラウザで `http://localhost:8000` が開きます。
- 終了するときは、コンソール画面を閉じてください(利用中は閉じないでください)。

## 3. 使い方

1. **ログイン**: 起動するとログイン画面が開きます。GROUPSESSION の ID・パスワードを入力して「ログイン」を押します。
   ID・パスワードはアプリのメモリ上にのみ保持され、アプリを終了すると破棄されます。
2. **マイグループを選ぶ**: 「マイグループ」のプルダウンから選ぶと、所属するメンバーが表示されます。
   マイグループは GROUPSESSION のスケジュール画面で作成・編集してください。
3. **メンバーを選ぶ**: 予定を確認したいメンバーにチェックを入れます(「全員」「解除」でまとめて切り替えられます)。
4. **期間を指定して取得**: 開始日・終了日を指定して「予定を取得」を押します(初期値は今日から2週間、一度に8週間まで)。
   1週間ずつ取得するため、期間が長いと少し時間がかかります。
5. **結果を見る**: 画面全体はスクロールせず、次の3つの領域で確認します(中身が多い場合は、各領域の中だけがスクロールします)。
   - **空き時間の候補**(中央): 条件に合う時間帯の一覧です。クリックすると、右下にその日の詳細が表示され、候補の時間帯に印が付きます。
   - **期間の俯瞰**(右上): 1日を1行として、時刻ごとの空き状況を色で表示します。緑は全員空き、黄色は一部空き(濃いほど空いている人が多い)、
     灰色は空きなしです。セルにマウスを乗せると空いていない人が表示され、行をクリックするとその日の詳細が表示されます。
   - 俯瞰と詳細の間の仕切りを上下にドラッグすると、それぞれの高さを変えられます(ダブルクリックで元の高さに戻ります。高さは次回も引き継がれます)。
   - **日の詳細**(右下): 選んだ日について、次のタブを切り替えて表示します。「◀ 前の日」「次の日 ▶」(またはキーボードの左右キー)で日を移動できます。
     - **タイムライン**: メンバーの予定を色の帯で表示します。帯にマウスを乗せると予定の内容が表示されます。
     - **この日の予定** / **全期間の予定**: 予定の一覧です。

左の「メンバー」「空き時間の条件」は、見出しをクリックすると折りたためます(折りたたんでも、選択人数や条件の要約が見出しに表示されます)。

次回起動時は、前回選んだマイグループとメンバーのチェックが自動で選ばれます。

### 空き時間の条件

左の「空き時間の条件」を変えると、取得し直さなくてもすぐに結果が変わります。

| 項目 | 初期値 | 説明 |
|------|--------|------|
| 業務開始・業務終了 | 9:00〜18:00 | この時間内で空き時間を探します |
| 昼休み | 12:00〜13:00 | この時間は候補に含めません |
| 判定の刻み | 30分 | この単位で空いているかを判定します |
| 必要な長さ | 1時間以上 | これより短い空き時間は候補に出しません |
| 参加できる人数 | 全員 | 「◯人以上」にすると、全員がそろわない場合の次善の候補を探せます |
| 土日・祝日を除く | オン | 休日を候補から除きます |

### 時刻のない予定の扱い

時刻のない予定(締め切りのメモなど)は、初期状態では空き時間の計算に含めません。
出張など、その日は実際に予定が埋まっている場合は、タイムラインの「終日」欄の予定をクリックしてください。
赤枠になり、その人はその日終日埋まっているものとして計算されます(もう一度クリックで元に戻ります。この切り替えは保存されません)。

## 4. 業務状況(出社割合)

画面上部の「業務状況(出社割合)」に切り替えると、メンバーごと・日ごとの出社割合(オフィスにいた時間 ÷ 勤務時間8時間)を確認・出力できます。
期間は一度に26週間まで取得できます。

出社割合は、1日の勤務時間を30分ごとの16枠に分けて「オフィス / オフィス外 / 休み」を判定し、オフィスの枠の数 ÷ 16 で求めます
(1日オフィスなら1、半休なら0.5、休暇・土日・祝日は0)。判定は、予定(予定名・時刻)をもとに学習済みのモデルが自動で行います。

### 4-1. 出社割合の見方

- 中央の表は、行が日付、列がメンバーです。数値が出社割合(0〜1)で、青が濃いほど出社割合が高いことを表します。土日と日本の祝日(振替休日を含む)は「休」(0)です。
- 一番下の行はメンバーごとの平日の平均、右端の列はその日の全員の平均です。
- 行をクリックすると、右側にその日の30分ごとの判定(オフィス=青 / オフィス外=オレンジ / 休み=灰色)が表示されます。
  枠の下の細い色の帯は、その時間の予定です(マウスを乗せると予定名が表示されます)。

### 4-2. 判定を直す

判定が実際と違う場合は、右側の表で直せます。上の「塗る値」を選んで、枠をクリック・ドラッグで塗り直します。
1日まるごとの場合は、行の右の「オ / 外 / 休」ボタンが便利です。

- **直した内容は保存されません。** CSVの出力にだけ反映されます。予定を取得し直したり、ツールを開き直したりすると元に戻るため、直したらその場でCSVを出力してください。

### 4-3. CSVの出力

「出社割合をCSVで出力」で、取得した期間のすべての日付・メンバーの出社割合を出力します(土日・祝日は0)。予定名は含まれません。

```
date,佐藤,鈴木,高橋,…
2026/11/02,0.9375,1,1,…
2026/11/03,0,0,0,…
```

- 1行目は `date` とメンバーの苗字です(同じ苗字の人が複数いる場合は、その人たちだけ氏名になります)。
- 日付は `yyyy/mm/dd` の形で、期間内の日付が抜けなく並びます。Excel でそのまま開けます。

## 5. 設定(config.json)

初期値を変えたい場合は、アプリを終了してから `config.json` をメモ帳などで編集してください。

| 項目 | 説明 |
|------|------|
| `groupsession_base_url` | GROUPSESSION のURL |
| `business_start` / `business_end` | 業務時間の初期値 |
| `lunch_start` / `lunch_end` | 昼休みの初期値 |
| `slot_minutes` | 判定の刻みの初期値(15 / 30 / 60) |
| `min_duration_minutes` | 必要な長さの初期値(30 / 60 / 90 / 120 / 180) |
| `max_weeks` | 空き時間の画面で一度に取得できる最大の週数 |
| `max_weeks_status` | 業務状況の画面で一度に取得できる最大の週数 |
| `last_group` / `last_member_ids` | 前回選んだマイグループとメンバー(自動で保存されます) |

## 6. トラブルシューティング

| 症状 | 原因・対処 |
|------|-----------|
| 「IDまたはパスワードが正しくありません」と表示される | GROUPSESSION に実際にログインできる ID・パスワードを入力してください |
| 途中でログイン画面が開く | GROUPSESSION のログインが切れました。ログインし直してください |
| 「GROUPSESSIONへのアクセスに失敗しました」と表示される | 社内ネットワークに接続しているか、GROUPSESSION が開けるかを確認してください |
| マイグループが表示されない | GROUPSESSION のスケジュール画面でマイグループを作成してください |
| 「ポート 8000 はすでに使われています」と表示される | すでにアプリが起動しています。開いているコンソール画面を確認してください |
| 「一度に取得できる期間は◯週間までです」と表示される | 期間を短くして、何回かに分けて取得してください(空き時間は8週間、業務状況は26週間まで) |
| 「モデル: 未学習(ルールで判定中)」と表示される | `data` フォルダに判定用のファイル(`office_model.joblib`)がありません。配布した担当者に問い合わせてください |
| 画面の表示がおかしい | ブラウザで Ctrl + F5 を押して再読み込みしてください |
