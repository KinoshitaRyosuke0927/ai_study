# データサイエンス基礎ドリル（プロトタイプ）

プログラミング未経験の社会人が、隙間時間にドリル形式で Python × データ分析の
基礎を身につけるハンズオン学習サイトのプロトタイプです。

> **1講座 10時間未満**（完成時 約8.5時間）・**1ドリル 3〜5分**・
> **環境構築不要**（ブラウザで完結）・**自動採点で即フィードバック**

---

## 動かし方（ローカル）

### 必要なもの
- Python 3.10 以上（検証済み: 3.12）
- ブラウザ（Chrome / Edge / Safari など）

### 手順
```bash
# 1. このフォルダで
bash start.sh
```

初回は自動で仮想環境の作成と依存インストールを行ったあと、サーバが起動します。

```bash
# または手動で
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8777
```

ブラウザで **http://localhost:8777** を開いてください。

---

## 何ができるか（プロトタイプ版）

- **講座ダッシュボード**: 全レッスン・所要時間・進捗バーを表示
- **レッスン画面**: 短い解説 + キーポイント + 例コード + ドリル
- **ドリル2種類**
  - コード穴埋めドリル: 空欄 `____` を埋めて実行・採点（出力照合、自動○✗）
  - 選択式ドリル: 択一回答（即判定 + 解説フィードバック）
- **進捗管理**: 解いたドリルをSQLiteに記録（合格の○が目次に付く）
- **実装済み**: 第1章「Pythonの基礎」（4レッスン / 11ドリル / 約60分）
- **準備中表示**: 第2章以降（リストと辞書・関数・pandas・可視化・総合ドリル）

## アーキテクチャ

```
ブラウザ（静的HTML/CSS/JS）
   │  REST API (JSON)
   ▼
FastAPI (Python)
   ├── /api/lessons     … レッスン・ドリル一覧/詳細
   ├── /api/.../run     … コード実行（採点なし）
   ├── /api/.../submit  … コード採点（出力照合）
   ├── /api/.../quiz    … 選択式判定
   └── /api/progress    … 進捗取得・リセット（SQLite）
```

```
backend/
  main.py        … FastAPI アプリ（API + 静的配信）
  curriculum.py  … カリキュラム・ドリルの定義（教材はここに集中）
  grader.py      … コード実行・自動採点（サブプロセス + timeout）
  db.py          … SQLite による進捗管理
  progress.db    … 実行時に自動作成される進捗DB
static/
  index.html     … 学習画面（SPA）
  css/style.css  … デザイン（ドリル帳テーマ・赤ペン判定）
  js/app.js      … フロントエンドのロジック
docs/
  00_コンセプトシート.md   … 企画（誰に・何を・どう）
  01_カリキュラム案.md     … 全6章の講義設計
```

## カリキュラムの追加方法

教材はすべて `backend/curriculum.py` の `LESSONS` にあります。
レッスン1件 = 辞書1つ、ドリルは `code_gap` / `quiz` の2形式です。

- **コード穴埋め**: `starter` の中の `____` を学習者が埋める。
  `expected` に想定される出力（1行ずつ）を書く。
- **選択式**: `choices` と `answer_index`（正解の番号）、`feedback`（解説）を書く。

```python
{
    "id": "l2-1",            # 一意なID
    "chapter": 2,            # 章番号
    "title": "レッスン名",
    "minutes": 90,           # 目安時間
    "status": "open",        # "open" or "coming_soon"
    "summary": "…",
    "explanation": ["…説明文…"],
    "keypoints": ["…キーポイント…"],
    "example": "…例コード…",
    "example_output": "…出力例…",
    "drills": [ { …ドリル定義… } ],
}
```

## セキュリティについて（大事な注意）

`grader.py` は学習者が送ったコードをそのまま OS の `python3` で実行します。
**これはプロトタイプ検証用の実装であり、そのままインターネット公開しては
いけません。** 公開する場合は次のいずれかで sandbox 化してください。

- Docker 等で隔離したコンテナ内で実行（ネットワーク遮断・リソース制限）
- `nsjail` / `gVisor` など OS レベルのサンドボックス + timeout とメモリ制限
- さらに送信コードのサイズ上限・同時実行数上限を設ける

また `progress.db` は単一ユーザー前提です。複数ユーザーにする場合は
`users` テーブルを追加し、`drill_id` に `user_id` を加えてください。
