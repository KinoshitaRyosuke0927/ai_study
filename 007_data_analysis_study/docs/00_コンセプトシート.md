# 00 コンセプトシート — データサイエンス基礎ドリル

## 1. サービス概要

| 項目 | 内容 |
|------|------|
| サービス名 | データサイエンス基礎ドリル（仮称） |
| 形態 | ブラウザで完結するハンズオン型のドリル学習サイト |
| キャッチ | 「読む」より「解く」。隙間時間で身につけるデータサイエンスの第一歩 |

## 2. ターゲット

- **プログラミング未経験の社会人**（20〜40代、文系・理系を問わず、リスキリング層）
- 「データサイエンティストに興味はあるが、環境構築で挫折した／時間がない」人
- スマホや仕事の合間に、1回数分で区切りつく学習を求める人

## 3. ゴール（学習成果）

- Pythonとデータ処理の「最も使う20%」を、挫折せずに習得する
- 1講座を**10時間未満**で完走できる
- 終了時点で「pandasで表データを読み込み・集計できる」「結果をグラフにできる」状態に達する

## 4. 形式（ドリル方式）

| 要素 | 設計 |
|------|------|
| 単位 | 1ドリル ＝ 3〜5分（穴埋めコード / 選択式） |
| 1レッスン | 短い解説（数段落） + キーポイント + 例コード + ドリル数問 |
| 1章 | 4レッスン程度 / 約90分 |
| 採点 | 自動。出力照合（コード） / 即時判定（選択式） |
| フィードバック | 赤ペン風の「正解/不合格」+ 期待出力との見比べ + ヒント |
| 進捗 | 解いたドリルに○が付き、進捗バーで見える化 |

## 5. 規模（完成時）

- 全6章 / 約8.5時間（510分）→ **10時間未満を確保**
- 内訳: 第1章 Pythonの基礎(60分)・第2章 リストと辞書(90分)・第3章 関数(60分)・第4章 pandas(120分)・第5章 可視化と統計(90分)・第6章 総合ドリル(90分)

## 6. 差別化ポイント

- **環境構築ゼロ**: ブラウザ内でPythonが動く（現行はサーバ側実行、将来は JupyterLite/Pyodide で完全ブラウザ完結）
- **挫折しにくい設計**: 1問3〜5分の達成感を連続させる・自動採点で待たせない
- **実務への接続**: 最後は架空企業の売上データで「読み込み→集計→報告」を一気通貫で体験

## 7. MVP（今回のプロトタイプ）

- 第1章「Pythonの基礎」を実装（4レッスン / 11ドリル / 約60分）
- 講座ダッシュボード + レッスン画面 + 実行/自動採点 + 進捗管理
- 第2章以降は「準備中」表示でロードマップを見せる

## 8. 計測・改善（本番想定）

- 指標: ドリル正解率 / 1問あたり所要時間 / レッスン離脱率 / 完走率
- データから難易度調整（正解率が高すぎ・低すぎのドリルを改稿）
- モニターでのαテスト → 説明粒度・ヒントの改善

## 9. 今後の展開

1. 第2〜6章のコンテンツ実装（データ定義に足すだけで追加可能）
2. 実行環境の本格化（JupyterLite/Pyodide でブラウザ完全完結、pandas等も対応）
3. 複数ユーザー対応（進捗DBに user 概念を追加）
4. 学習データ収集と難易度チューニング
