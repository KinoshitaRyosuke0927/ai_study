## 章ごとの設計

### 第1章 Pythonの基礎（60分 / 実装済み ✓）
- **ゴール**: 「Pythonって何ができるか」より「1行書けた」を積む
- **項目**: 変数と出力・計算・条件分岐(if/elif/else)・ループ(for/range)・リストの基本
- **構成**: 4レッスン × 15分（1-1 変数と出力 / 1-2 条件分岐 / 1-3 ループとリスト / 1-4 総仕上げ）
- **ドリル例**: 「17-9をprintで出力」「80点以上ならA」「1〜10の合計を計算」

### 第2章 リストと辞書（90分 / 準備中）
- **項目**: リストの索引・スライス・追加削除 / 辞書（キー:値）の基本・ループとの組み合わせ
- **ドリル例**: 「リスト [3,1,4] の2番目を出力」「商品名→価格の辞書から合計を計算」

### 第3章 関数とモジュール（60分 / 準備中）
- **項目**: def の書き方・引数と戻り値・スコープ / import と標準ライブラリ
- **ドリル例**: 「消費税を計算する関数を作る」「math モジュールで平方根」

### 第4章 pandas で表データ処理（120分 / 準備中）
- **項目**: Series/DataFrame・CSV読み込み・列の選択と条件抽出・groupby集計・欠損値処理
- **ドリル例**: 「売上CSVを読み込み、商品ごとの合計を出す」
- **★ 実データ（汚いデータ含む）を用意し、実務感を出す**

### 第5章 可視化と統計のきほん（90分 / 準備中）
- **項目**: matplotlibの基本（折れ線・棒・ヒストグラム）/ 平均・中央値・分散・相関係数の意味
- **ドリル例**: 「売上推移を折れ線グラフにする」「各月の平均売上を計算」

### 第6章 総合ドリル: 売上データ分析（90分 / 準備中）
- **案件**: 架空企業「〇〇ストア」の1年分の売上データ
- **流れ**: データの読み込み → 異常値チェック → 月次集計 → グラフ → 「どの施策が効いたか」を1文で報告
- **評価**: 出力照合（集計値）+ 提出レポート（自由記述）
