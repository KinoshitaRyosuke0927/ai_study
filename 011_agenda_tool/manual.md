# アジェンダ作成ツール 利用手順

Mattermost・GROUPSESSIONから投稿・記事を取得し、AIでAIMのアジェンダ(全体共有事項)を作成できるアプリケーションです。作成したアジェンダは社内wiki(GROWI)へ公開することもできます。

## 1. フォルダ構成

配布フォルダには以下が含まれています。

```
agenda_tool/
├── agenda_tool.exe     ... アプリ本体
├── 起動.bat            ... ダブルクリックで起動＆ブラウザを開くショートカット
├── .env                ... Mattermost・GROUPSESSION・GROWI・Azure OpenAI の接続情報
├── settings.ini        ... 対象チャンネル・フォーラム・公開先等の設定(自分で編集可能)
├── agenda_template.txt ... アジェンダのひな形(自分で編集可能)
└── _internal/          ... アプリ動作用の内部ファイル(触らないでください)
```

## 2. 事前準備

このアプリは追加のソフトウェアインストールは不要です。ただし、利用開始前に `.env` と `settings.ini` の内容を環境に合わせて設定してください。

### 2-1. `.env` の設定

`agenda_tool.exe` と同じフォルダの `.env` に、以下の接続情報が設定されている必要があります。

```
AZURE_OPENAI_ENDPOINT=https://your-resource.services.ai.azure.com/openai/v1
AZURE_OPENAI_KEY=your-api-key

MATTERMOST_URL=https://chat.jbdcl.com
MATTERMOST_TOKEN=（パーソナルアクセストークン）

GROUPSESSION_BASE_URL=https://gs.jbdcl.com/gsession

GROWI_BASE_URL=https://wiki.jbdcl.com/
GROWI_API_TOKEN=（GROWIのAPIトークン）
```

- Azure OpenAIの接続情報については設定不要です(配布時に設定済み)。
- `MATTERMOST_TOKEN` は、Mattermostの「設定」→「セキュリティ」→「パーソナルアクセストークン」から発行します。
- `GROWI_API_TOKEN` は、GROWIの画面右上のユーザー名をクリック→設定画面→「API設定」タブ→「API Tokenを更新」ボタンから取得できます。
- GROUPSESSIONのログインID・パスワードは `.env` には設定しません。画面の「GROUPSESSIONログイン」ボタンから入力してください(4-1参照)。アプリを終了するとログイン情報は破棄されるため、次回起動時は再度ログインが必要です。

### 2-2. `settings.ini` の設定

対象チャンネル・フォーラム・期間・公開先を `settings.ini` で設定します。

```ini
[history]
read_date = 30

[groupsession]
forum_sid = 5, 15
read_date = 30

[growi]
channel_list = AIビジネス連絡事項, AIC 連絡事項
root_path = /2000_開発者向け/2000_開発者向け/2YYY_組織/AIビジネス研究室/100_AIM
```

| 項目 | 説明 |
|------|------|
| `history.read_date` | Mattermost投稿の取得期間の初期値(今日から遡る日数) |
| `groupsession.forum_sid` | 新着記事を取得するGROUPSESSIONフォーラムのID(カンマ区切りで複数指定可) |
| `groupsession.read_date` | GROUPSESSION記事の取得期間の初期値(今日から遡る日数) |
| `growi.channel_list` | 「履歴・新着記事を取得」で参照するMattermostチャンネルの表示名一覧(カンマ区切り) |
| `growi.root_path` | アジェンダの公開先GROWIページの親パス(この下に「年/月」のページが作成・更新される) |

画面の取得期間の初期値は、`history.read_date` と `groupsession.read_date` のうち長い方になります。

チャンネルの表示名を間違えると、画面にエラーメッセージが表示されます(6章参照)。

### 2-3. `agenda_template.txt` の設定

生成されるアジェンダのひな形です。`{{YEAR}}`(年)・`{{MONTH}}`(月)・`{{AGENDA_BODY}}`(AIが生成した全体共有事項)の3つのプレースホルダー以外は自由に編集できます。編集後はアプリの再起動は不要で、次回「アジェンダを作成」した際から反映されます。

## 3. アプリの起動方法

`起動.bat` をダブルクリックしてください。自動的にアプリが起動し、既定のブラウザで `http://localhost:8000` が開きます。

(`起動.bat` を使わず `agenda_tool.exe` を直接ダブルクリックした場合は、手動でブラウザから `http://localhost:8000` にアクセスしてください。)

起動時に黒いコンソール画面が表示されますが、これはアプリのログ出力用の画面です。閉じるとアプリが終了するため、利用中は閉じないでください。

## 4. 使い方

画面右側にある、上下2つのエリアの境界線はドラッグして高さを調整できます。

画面右上の「GROUPSESSIONログイン」ボタンの右に「フィルタ強度」スライダーがあります(0~1の範囲で0.1刻み、初期値0.5)。Mattermost投稿・GROUPSESSION記事を取得すると、AI(ローカルで動作する学習済みモデル)が各投稿・記事に「リマインドが必要そうか」を0~1のスコアで判定し、このスライダーで設定した値以上のスコアのものだけが一覧に表示されます。値を大きくするほど絞り込みが厳しくなり、小さくするほど多くの投稿・記事が表示されます。横の「?」アイコンにカーソルを合わせると説明が表示されます。

### 4-1. GROUPSESSIONログイン

画面左上の「GROUPSESSIONログイン」ボタンをクリックするとモーダルが開きます。ID・パスワードを入力して「ログイン」をクリックしてください。ログインに成功するとモーダルが閉じ、ボタンの文字が緑色の「GROUPSESSIONログイン済」に変わります。失敗した場合はモーダル内にエラーメッセージが表示されます。

- ログイン情報はアプリ(サーバ)のメモリ上にのみ保持され、ファイルには保存されません。アプリを終了すると破棄されるため、次回起動時は再度ログインが必要です。
- 未ログインの間は、「履歴・新着記事を取得」ボタンは非活性になっています。

### 4-2. アジェンダの作成・公開

1. 取得開始日・取得終了日を指定して「履歴・新着記事を取得」をクリックします。`settings.ini` の `growi.channel_list` に設定した全チャンネルのMattermost投稿と、GROUPSESSIONの新着記事をまとめて取得します。
2. 「取得した投稿一覧」の右にある「日時順」「投稿者順」「取得元順」ボタンで一覧を並び替えられます(取得元順はGROUPSESSIONが上、Mattermostが下になります)。
3. 左下の一覧から項目をクリックすると詳細が表示され、チェックボックスでアジェンダに含める項目を選択します。「アジェンダを作成」ボタンは、1件以上チェックすると活性化します。
4. 「アジェンダを作成」をクリックすると、チェックした項目をもとにAIが部署定例会の「全体共有事項」を生成し、`agenda_template.txt` のひな形に埋め込んで右下のテキストエリアに表示します。
5. 内容を確認・編集し、「公開先: 年」「公開先: 月」を指定します。「公開範囲」のスイッチで「公開」(誰でも閲覧可能)/「自分のみ公開」(自分だけが閲覧可能)を切り替えられます(初期状態は「公開」)。「wikiへ公開」をクリックすると、`settings.ini` の `growi.root_path` 配下に「年/月」のページとして公開されます(既に同じ年月のページがある場合は上書き更新されます)。
   - 既存ページの公開範囲を「自分のみ公開」に切り替えて公開した場合、ページが新規に作り直されるため**URLが変わります**。以前のURLを共有していた場合は無効になります(「wikiへ公開」ボタン横の「?」アイコンにカーソルを合わせると注意書きが表示されます)。

添付ファイルのダウンロードをしたい場合は、閲覧しているブラウザでGROUPSESSIONに別途ログイン済みである必要があります。

## 5. アプリの終了方法

起動中のコンソール画面を閉じるか、`Ctrl + C` を押してください。

## 6. トラブルシューティング

| 症状 | 原因・対処 |
|------|-----------|
| 起動直後にコンソールが閉じてエラーで落ちる(`KeyError: 'GROUPSESSION_BASE_URL'` 等) | `.env` がexeと同じフォルダに無い、または内容が未設定です。2-1を確認してください。 |
| 「settings.iniのチャンネル『◯◯』が見つかりませんでした」と表示される | `settings.ini` に設定したチャンネルの表示名が、実際のMattermostチャンネル名と一致していません。2-2を確認してください。 |
| 「Mattermost APIエラー」と表示される | `MATTERMOST_TOKEN` が無効・期限切れの可能性があります。Mattermostでパーソナルアクセストークンを再発行してください。 |
| 「GROUPSESSIONにログインしてください」と表示される | GROUPSESSIONにログインしていません。4-1の手順でログインしてください。 |
| GROUPSESSIONログイン時に「IDまたはパスワードが正しくありません」と表示される | 入力したID・パスワードが誤っています。GROUPSESSIONに実際にログインできる情報を再入力してください。 |
| 「GROUPSESSIONへのアクセスに失敗しました」と表示される | GROUPSESSION側の一時的な不調、通信エラーなどの可能性があります。 |
| 「GROWIへの公開に失敗しました」と表示される | `GROWI_API_TOKEN` が無効、または `growi.root_path` の指定が誤っている可能性があります。 |
| 「モデルによる投稿の絞り込みに失敗しました」と表示される | アプリ内部のAIモデルの読み込みに失敗している可能性があります。`_internal` フォルダが欠損・破損していないか確認し、改善しない場合は配布元に問い合わせてください。 |
| 表示されるべき投稿・記事が一覧に出てこない、または関係のない投稿・記事まで表示される | 「フィルタ強度」スライダーの値を調整してください。値を下げると表示件数が増え(見逃しは減るが不要な投稿も増える)、上げると表示件数が減ります(絞り込みは厳しくなるが見逃しも増える可能性があります)。 |
| ブラウザで画面が表示されない | コンソール画面にエラーが出ていないか確認し、`http://localhost:8000` に手動でアクセスしてください。すでに同じポートで別プロセスが起動している場合は、そちらを終了してから再度お試しください。 |
