# 石井さんのコンペティション
## 目的
住宅情報から住宅価格を予測したい

## データ概要
学習用データ（train_data.csv）は200件の住宅データで構成されており, 各列の内容は以下の通りです
予測データ（test_data.csv）にはprice_10kyen列がありません

| 列名 | 説明 |
| --- | --- |
| id | 物件のID（連番） |
| area_m2 | 専有面積（m2） |
| age_years | 築年数（年） |
| station_walk_min | 最寄り駅までの徒歩時間（分） |
| floor | 所在階 |
| rooms | 部屋数 |
| is_south_facing | 南向きかどうか（0:いいえ, 1:はい） |
| has_parking | 駐車場の有無（0:なし, 1:あり） |
| ward_type | 所在エリア（区）の種別を表すカテゴリ（1〜3） |
| renovation_done | リノベーション済みかどうか（0:未実施, 1:実施済み） |
| school_walk_min | 最寄り学校までの徒歩時間（分） |
| price_10kyen | 住宅価格（単位：万円）。予測対象の目的変数 |

## 提出形式
以下の形式のcsvファイルで提出します(submission.csv参照)

| id | price_10kyen |
| --- | --- |
| 1001 | 0.0 |
| 1002 | 0.0 |
| 1003 | 0.0 |
| ... | ... |

## 具体的な活動
Ridge回帰の実装参考：[リッジ回帰で値を予測する際のPythonの実装](https://pydocument.hatenablog.com/entry/2024/04/13/000527)
線形回帰の実装参考：[Scikit-learn で線形回帰](https://qiita.com/0NE_shoT_/items/08376b08783cd554b02e#%E7%B7%9A%E5%BD%A2%E5%9B%9E%E5%B8%B0%E3%83%A2%E3%83%87%E3%83%AB%E3%81%AE%E6%A7%8B%E7%AF%89)

### 1. 特徴量の選定
住宅価格に影響しそうな要素を選ぶ

### 2. 学習用データの前処理
学習データから予測に使用する列 + 予測する列のみ取り出す

### 3. モデルの学習
パラメータを設定して学習を行う

### 4. 予測の実行
学習したモデルで, テストデータに対して予測を行う

### 5. コンペティション提出
石井さんのコンペティションサイトにアクセスして予測結果を提出

## ex. 発展的学習
### ex-1. すべての要素を特徴量として予測
- いくつかの特徴量のみを選択したときと比べて結果はどうなったか
- なぜそのような結果になったと考えられるか

### ex-2. 住宅価格を対数変換して予測
- いくつかの特徴量のみを選択したときと比べて結果はどうなったか
- 対数変換するとどのような恩恵があると考えられるか

### ex-3. Ridge回帰ではなく線形回帰で予測
- Ridge回帰と比べて結果はどうなったか
- なぜそのような結果になったと考えられるか
