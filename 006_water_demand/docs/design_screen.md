## SCR-002 水の注文量登録画面

### 画面キャプチャ

<!-- 画面キャプチャ画像をここに添付 -->

---

### 画面概要

月ごとの水の注文量と残量の実績を登録・編集する画面。

### 画面構成

| 要素 | 種類 | 内容 |
|------|------|------|
| 戻るボタン（←） | リンク | メニュー画面（`/`）へ遷移 |
| タイトル | テキスト | 「水の注文量登録」 |
| 登録ボタン | ボタン | 編集内容をCSVに保存 |
| メッセージ表示領域 | テキスト | 登録成功/失敗メッセージを3秒間表示 |
| ＋月追加ボタン | ボタン | 新規行を先頭に追加（翌月を自動設定） |
| 一覧テーブル | テーブル | 月ごとの実績データ一覧（年月の新しい順） |

### テーブル列定義

| 列名 | 内容 | 入力形式 |
|------|------|----------|
| 年月 | 対象年月（例：2025年4月） | 表示のみ / 追加時はmonth入力 |
| 注文量 (L) | その月の注文量 | 数値入力（小数第1位まで） |
| 残量 (L) | その月の残量 | 数値入力（小数第1位まで・空欄可） |
| 操作 | 修正/削除ボタン | ボタン操作 |

### 操作フロー

```
既存行の修正：
  修正ボタンクリック → 入力フィールドが表示される（編集モード）
  確定ボタンクリック → バリデーション後、表示モードに戻る

新規行の追加：
  ＋月追加ボタンクリック → 先頭に入力行が追加される（翌月を自動セット）
  確定ボタンクリック → バリデーション後、表示モードに変わる

保存：
  登録ボタンクリック → 全行のデータをPOST /water_demand/save に送信
  → 成功時：「登録しました」を3秒表示
  → 失敗時：「登録に失敗しました」を表示
```

### バリデーション

- 注文量は必須入力
- 注文量・残量は小数第1位までの数値のみ（正規表現：`^\d+(\.\d{0,1})?$`）
- 同一年月の重複登録不可

## SCR-003 出社状況登録画面

### 画面キャプチャ

<!-- 画面キャプチャ画像をここに添付 -->

---

### 画面概要

社員ごとのAIC出社カレンダーを確認・更新する画面。カレンダー形式で出社/不在を視覚的に管理できる。

### 画面構成

| 要素 | 種類 | 内容 |
|------|------|------|
| 戻るボタン（←） | リンク | メニュー画面（`/`）へ遷移 |
| タイトル | テキスト | 「出社状況登録」 |
| 登録期間表示 | テキスト | CSVの最小〜最大日付を表示 |
| 社員選択プルダウン | セレクトボックス | CSVの `emp_nn` 列を選択肢として表示 |
| 表示ボタン | ボタン | 選択社員のカレンダーを取得・表示 |
| 更新ボタン | ボタン | 変更内容をCSVに保存 |
| メッセージ表示領域 | テキスト | 更新成功/失敗メッセージを3秒間表示 |
| 期間・曜日指定一括変更パネル | パネル | 期間と曜日を指定して出社/不在を一括設定 |
| 凡例 | 表示 | 出社（青）・不在（グレー）の色説明 |
| カレンダー表示エリア | カレンダー | 年ごとにアコーディオン表示、月ごとに3列グリッド配置 |

### カレンダー操作

| 操作 | 動作 |
|------|------|
| 日付セルをクリック | 出社 ↔ 不在 を個別切り替え |
| 曜日ヘッダーをクリック | その月のその曜日をまとめて切り替え（全員出社なら全不在、それ以外は全出社） |
| 年ラベルをクリック | 年単位でアコーディオン開閉（最新年はデフォルト展開） |

### 一括変更パネル

| 入力項目 | 内容 |
|----------|------|
| 期間（開始〜終了） | 対象期間を日付で指定 |
| 曜日 | 対象曜日をチェックボックスで複数選択（日〜土） |
| 出社にするボタン | 条件に合う日付を一括で出社にセット |
| 不在にするボタン | 条件に合う日付を一括で不在にセット |

### 操作フロー

```
表示：
  社員選択 → 表示ボタンクリック → GET /work_day/data?emp=emp_nn
  → カレンダーをレンダリング

更新：
  カレンダーで出社/不在を変更 → 更新ボタンクリック
  → POST /work_day/save に変更データ送信
  → 成功時：「更新しました」を3秒表示
  → 失敗時：「更新に失敗しました」を表示
```

## SCR-004 注文量予測画面

### 画面キャプチャ

<!-- 画面キャプチャ画像をここに添付 -->

---

### 画面概要

翌月の水の注文量をモデルで予測し、結果を確認・実績登録する画面。また使用データの参照期間と更新日時を確認でき、気象データの最新化も行える。

### 画面構成

| 要素 | 種類 | 内容 |
|------|------|------|
| 戻るボタン（←） | リンク | メニュー画面（`/`）へ遷移 |
| タイトル | テキスト | 「注文量予測」 |
| 使用データテーブル | テーブル | 予測に使用する4データソースの情報を表示 |
| 注文量を予測ボタン | ボタン | 予測APIを実行（実行中は無効化） |
| 予測結果カード | カード | 予測結果の詳細表示（予測実行後に表示） |

### 使用データテーブル列定義

| 列名 | 内容 |
|------|------|
| データ | データソース名 |
| 参照期間 | データの対象期間 |
| 更新日時 | CSVファイルの最終更新日時 |
| 操作 | 編集リンク or 最新情報取得ボタン |

### 操作列の内容

| データ名 | 操作 |
|----------|------|
| 水の注文量実績 | 「編集」リンク → SCR-002 へ遷移 |
| JBD営業日カレンダー | なし |
| AIC出社カレンダー | 「編集」リンク → SCR-003 へ遷移 |
| 気候情報 | 「最新情報を取得」ボタン → 外部APIを呼び出してCSVを更新 |

### 予測結果カードの表示項目

| 項目 | 内容 |
|------|------|
| カードヘッダー | 「予測結果 — YYYY年MM月」 |
| 営業日数 | 予測対象月の営業日数（日） |
| 1日あたり出社人数 | 予測対象月の平均出社人数（人/日） |
| 月平均気温（前年同月実績） | 前年同月の平均気温（℃） |
| 予測注文量 | モデルの生の予測値（L） |
| 推奨注文量（20L単位）※ハイライト | 20L単位に切り上げた推奨値（L） |
| 推奨注文量を実績として登録ボタン | 推奨注文量を `water_demand.csv` に追加保存 |

### 操作フロー

```
予測実行：
  注文量を予測ボタンクリック → POST /predict/run
  → 成功時：予測結果カードを表示
  → エラー時：エラーメッセージを表示（データ不足など）

気象データ更新：
  最新情報を取得ボタンクリック → POST /predict/update-weather
  → 成功時：使用データテーブルを再読み込み（GET /predict/data-info）
  → 失敗時：アラートでエラーメッセージを表示

実績登録：
  推奨注文量を実績として登録ボタンクリック → POST /predict/register
  → 成功時：「登録しました」を表示、使用データテーブルを再読み込み
  → 失敗時：「登録に失敗しました」を表示
```
