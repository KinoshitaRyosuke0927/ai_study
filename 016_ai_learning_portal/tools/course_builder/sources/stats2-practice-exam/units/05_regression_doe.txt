<!-- @question

answer: I と III のみ
title: 重回帰の出力の読み取り
hint: 残差の自由度は n − p − 1 です。各係数の p 値を 0.05 と比べます。予測値は回帰式に値を代入します。
explanation: I. x1 の p 値 0.005 は 0.05 より小さいので正しい。II. x2 の p 値 0.170 は 0.05 より大きく、x2 の係数が 0 でないとはいえないので誤り。III. 予測値は 15.2 + 1.26 × 10 + 0.35 × 20 = 15.2 + 12.6 + 7.0 = 34.8 なので正しい。

40 組のデータで、$y$ を 2 つの説明変数 $x_1$, $x_2$ で重回帰分析したところ、次の出力が得られた。

```
            coef   std err       t    P>|t|
const    15.2000     4.000   3.800    0.001
x1        1.2600     0.420   3.000    0.005
x2        0.3500     0.250   1.400    0.170
```

次の記述 I〜III のうち、正しいものの組み合わせを選べ。

I. 有意水準 5% で、$x_1$ の偏回帰係数は 0 でないと判断できる。

II. 有意水準 5% で、$x_2$ が大きいほど $y$ は大きいと判断できる。

III. $x_1 = 10$、$x_2 = 20$ のときの $y$ の予測値は 34.8 である。

- I のみ
- II のみ
- I と II のみ
- I と III のみ
- I と II と III

-->
ある回帰分析の残差プロット(横軸:予測値、縦軸:残差)は次のとおりであった。

![残差プロット](images/u5_residual.png)

このプロットから、成り立っていないと疑われる回帰モデルの仮定として最も適切なものを選べ。

- 誤差の平均が 0 である。
- 誤差の分散が一定である(等分散性)。
- 説明変数が正規分布に従う。
- 説明変数が1つである。
- 回帰係数が正である。
