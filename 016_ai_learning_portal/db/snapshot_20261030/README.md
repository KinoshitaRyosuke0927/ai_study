# DB スナップショット(2026-10-30 時点)

作成元の環境の DB を、2026-10-30 時点の状態のまま別の環境に再現するためのファイルです。
講座・ユーザ・受講記録を含むすべてのデータが入っています。

| ファイル | 内容 |
|---|---|
| `schema_and_data.sql` | 全テーブルの定義と全データ(既存のテーブルは作り直す) |
| `images/` | 講座の画像(82 枚)。画像は DB ではなくファイルで管理しているため、SQL とは別にコピーする |

### 含まれるデータ

| 内容 | 件数 |
|---|---|
| ユーザ | 2名(`admin` / `r-kinoshita`。パスワードは作成元と同じ) |
| 講座 | 11件(公開中 10件:統計検定2級対策 6講座・タイタニック 4講座、下書き 1件:scikit-learn入門) |
| 単元 / セル / 問題(演習・小テスト) | 71 / 840 / 471 |
| データファイル / 画像 | 10 / 82 |
| 受講記録 | 提出 159件・単元の完了 10件・小テストの受験 4件・修了 1件 |
| AI による講座作成の記録 | ジョブ 1件・AI 呼び出し 161件 |

Alembic の版数も含むため、取り込み後に `alembic upgrade head` を実行しても何も変わりません。

## 手順

`db/` フォルダの `setup_db.ps1`(Windows)/ `setup_db.sh`(macOS・Linux)で、DB の作成・このスナップショットの登録・講座の画像のコピーをまとめて行います。
手順の詳細は [../README.md](../README.md) を参照してください。

## 注意

- `schema_and_data.sql` は **既存のテーブルを削除して作り直します**。取り込み先の DB にあるデータはすべて消えます。
- ユーザのパスワード(ハッシュ)も作成元と同じになります。別の人が使う環境では、`backend/` で
  `python -m app.cli set-password --login <ログイン名>` を実行してパスワードを変更してください。
- 受講記録・AI に渡したプロンプトの記録など、部署内の情報を含みます。社外に渡したり、公開リポジトリに置いたりしないでください。
- `.env` の `APP_SECRET_KEY` は DB に含まれません。取り込み先で別の値にしても、再ログインが必要になるだけでデータには影響しません。
