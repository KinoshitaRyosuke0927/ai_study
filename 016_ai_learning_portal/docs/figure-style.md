# 講座の図のスタイル

講座の説明・問題文に載せる図(グラフ)は、すべて同じスタイルで描きます。
基準は手本講座 [`content/stats2-descriptive`](../content/stats2-descriptive/images/) の図です(2026-10-25 決定)。

スタイルの定義は [`backend/app/ai/figure_style.py`](../backend/app/ai/figure_style.py) の1か所にまとめています。

| 定義 | 内容 | 使う場面 |
|---|---|---|
| `FIGURE_STYLE_CODE` | matplotlib の設定(色・文字の大きさ・柱の白い枠線など)と色の変数 | 図を描くコードの前に実行する(手本の図を作るスクリプト、AI が作る図) |
| `FIGURE_RC` / `MATPLOTLIBRC` | 上の matplotlib の設定を matplotlibrc の形にしたもの | ブラウザ内の Python の起動時に置き、**受講者のコードで描くグラフ**にも同じスタイルを適用する(`/api/config` で配布。講座ツールの build-course も同じものを使う) |
| `FIGURE_STYLE_GUIDE` | 描き方の指示(英語のラベル、横並び、補助線と注釈など) | AI に図を作らせるときのプロンプトに含める |

## 主な決まり

| 項目 | 決まり |
|---|---|
| 色 | 柱・折れ線は `PRIMARY`(#3b7f86)、注目させる線・注釈は `ACCENT`(#c0603a)。カテゴリの塗り分けは `CATEGORY_COLORS`(同系色の濃淡) |
| 文字 | 図の中はすべて英語(日本語フォントが無いため)。日本語の説明は図の前後の本文に書く |
| 並べ方 | 比べる図は横に並べる(2〜5 枚、横 10〜14 インチ・高さ 2.6〜4 インチ) |
| ヒストグラム | 柱の間をあけず、白い枠線で区切る。目盛りを階級の区切りに合わせる |
| 読み取りの補助 | 読み取らせたい値に、点線・破線の補助線と短い注釈("about 52" など)を付ける |
| 問題の図 | 答えが図から直接わかる注釈や数値は入れない |
| 出力 | PNG、100 dpi。講座フォルダの `images/` に置き、Markdown から `![説明](images/ファイル名)` で参照する |

デザインを変えるときは `figure_style.py` だけを直し、既存の図を作り直します。
