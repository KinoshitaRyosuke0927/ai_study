# 講座ノートブックの書き方

Jupyter / VS Code / Google Colab で書いた `.ipynb` を、そのまま講座として取り込めます。
講座の取り込みは `python -m app.cli import-course <講座フォルダ>`(`backend/` で実行)で行います。
画面からは、講座エディタの「.ipynb から単元を追加」で、既存の講座に単元を1つずつ追加できます。
見本は、コードを書かない講座が [`content/stats2-descriptive/`](../content/stats2-descriptive/)、コード演習を含む講座がテスト用の [`backend/tests/fixtures/sample-course/`](../backend/tests/fixtures/sample-course/) です。

## 講座フォルダの構成

```
statistics-basics/
  course.json            講座情報と単元の並び順
  01_data_types.ipynb    単元(1ファイル = 1単元)
  02_frequency.ipynb
  data/
    scores.csv           演習で使うデータ(任意)。コードからは pd.read_csv("scores.csv") で読める
                         (逆に、セルで df.to_csv("submission.csv") などと書き出したファイルは、受講者が画面からダウンロードできる)
  images/
    u01_shapes.png       説明・問題文で使う画像(任意)。Markdown から ![説明](images/u01_shapes.png) で参照する
```

### course.json

```json
{
  "slug": "statistics-basics",
  "title": "統計の基礎",
  "summary": "講座の説明文",
  "level": "basic",
  "tags": ["統計", "pandas"],
  "outcomes": ["この講座で身につくこと", "..."],
  "libraries": ["pandas", "numpy", "matplotlib"],
  "prerequisites": [],
  "status": "published",
  "units": [
    { "file": "01_data_types.ipynb", "minutes": 20 },
    { "file": "02_frequency.ipynb", "minutes": 25 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `slug` | 講座の識別名(英数字とハイフン)。URL に使われる |
| `level` | `basic`(基礎)/ `intermediate`(応用)/ `advanced`(実践) |
| `prerequisites` | 先に受講をおすすめする講座(前提講座)の `slug` の一覧(先に取り込まれている必要がある)。講座の詳細画面に表示するだけで、修了していなくても受講できる |
| `status` | `published`(公開)/ `draft`(下書き。管理者にだけ見える) |
| `units` | 単元の並び順と目安時間(分) |

## 単元ノートブックの書き方

### 1. 先頭のセル:タイトルと概要(Markdown)

```markdown
# 代表値:平均・中央値・最頻値
3つの代表値の違いと、外れ値が与える影響を学びます。
```

1行目の `# ` 見出しが単元タイトル、2行目以降が講座詳細に表示される概要になります。

### 2. 学習目標(任意、Markdown)

```markdown
## 学習目標
- 平均・中央値・最頻値の違いを説明できる
- pandas で代表値を計算できる
```

`## 学習目標` で始まるセルの箇条書きは、単元画面の「学習目標」の枠に表示されます。

### 3. 説明セルと例題セル

- Markdown セル → 説明セル(表・数式 `$...$` が使えます)。`## 見出し` は単元画面の目次に出ます
- 下記の記号で始まらないコードセル → 例題セル(受講者が自由に実行できます)

### 4. 演習(3〜4つのセルの組)

| セル | 1行目 | 内容 |
|---|---|---|
| Markdown | (何でもよい) | **問題文**。演習の直前の Markdown セルが問題文になります |
| コード | `# @starter` | 受講者に最初に表示する **初期コード**(空欄 `____` を含めてよい) |
| コード | `# @solution` | 作成者の **解答**。**実行して出力を保存しておく**(この出力が想定出力になります) |
| コード | `# @test` | (任意)テストコード。`@grading: test` の場合は必須 |

解答セルの先頭には、`# @項目: 値` の形で設定を書けます。

```python
# @solution
# @title: 外れ値を含むデータの代表値
# @hint: pandas の Series には .mean() と .median() メソッドがあります。
# @explanation: 平均は大きく動きましたが、中央値はほとんど変わりません。
import pandas as pd
scores = pd.Series([62, 75, 75, 81, 94, 58, 75, 88, 300])
print(f"平均: {scores.mean():.2f}")
print(f"中央値: {scores.median()}")
```

| 設定 | 内容 |
|---|---|
| `@title` | 演習のタイトル |
| `@hint` | 「ヒント」ボタンで表示する文 |
| `@explanation` | 正解したときに表示する解説 |
| `@grading` | `output`(出力一致、既定)または `test`(テストコード) |
| `@tolerance` | 数値比較の許容誤差(既定 `1e-6`) |

### 5. 選択式・数値入力・表形式の演習(コードを書かない演習)

概念の理解を確かめる問題は、コードにせず、ブラウザ上で選んで(入力して)答える演習にできます。
小テストと同じ設定ブロック `<!-- @question ... -->` を先頭に置いた Markdown セル1つが、演習1問になります(書き方は「小テストの書き方」を参照)。
単元の演習では、設定ブロックに次の項目も書けます。

| 設定 | 内容 |
|---|---|
| `title` | 演習のタイトル |
| `hint` | 「ヒント」ボタンで表示する文 |

`type` は `choice` / `numeric` / `matrix` のいずれかです(コードの演習は上の `# @starter` の書き方を使います)。

**表形式の選択(`matrix`)**:複数の項目を、共通の選択肢から1つずつ選んで分類する問題です。本文の最後に Markdown の表を書きます。
見出し行の2列目以降が選択肢、各行の1列目が分類する項目です(表の残りのマスは空欄のままにします)。
`answer` には、行の順に正解の選択肢をカンマ区切りで並べます。すべての行が正しいときに正解です。
表のマスの中に `|` を書くことはできません(`\|` と書いても列の区切りとして扱われます)。項目名・選択肢は `|` を使わない言い回しにします。

```markdown
<!-- @question
type: matrix
answer: 質的・名義, 量的・離散, 質的・順序
title: 変数の種類の判定
hint: 「平均に意味があるか」「順序があるか」で判断します。
explanation: 満足度は数字ですが、間隔が等しい保証がないため順序尺度です。
-->
各列は、どの種類の変数ですか。行ごとに1つ選んでください。

| 列 | 質的・名義 | 質的・順序 | 量的・離散 | 量的・連続 |
|---|---|---|---|---|
| `region`(地域) | | | | |
| `members`(世帯人数) | | | | |
| `satisfaction`(満足度 1〜5) | | | | |
```

選択肢と項目名にはカンマ(`,` `、`)を使わないでください(`answer` の区切りと区別できなくなります)。
選択式・数値入力・表形式の演習は、作成者が正解を書いているため、取り込んだ時点で検証済みになります。

### 6. 画像

講座フォルダの `images/` に画像を置き、説明・問題文の Markdown から `![説明](images/ファイル名)` で参照します。
Jupyter / VS Code ではそのまま表示され、取り込むとアプリでも表示されます(取り込み時に `image:ファイル名` へ読み替えます)。

- 形式は PNG / JPEG / GIF / WebP、1枚 2MB まで(SVG は使えません)。
- ファイル名は半角英数字で始め、半角英数字と `. _ -` だけにします(例:`u01_shapes.png`)。
- 講座エディタの「画像」から追加した画像は、`![説明](image:ファイル名)` で参照します。
- 図に日本語を入れると文字化けしやすいため、matplotlib で作る図のラベルは英語にします。
- グラフの色・描き方は [figure-style.md](figure-style.md) の共通スタイルにそろえます。

### 採点方式

- **出力一致(`output`)**:受講者のコードの出力(`print` の内容と、セル最後の式の値)を、解答セルに保存された出力と比べます。
  行末の空白や、数値の桁数による列揃えの違いは無視します。数値は許容誤差内なら一致とみなします。
- **テストコード(`test`)**:受講者のコードを実行したあと、同じ環境で `# @test` セルを実行し、すべての `assert` が通れば正解です。
  結果が一意に決まらない問題(乱数を使う、形式が自由など)に向いています。

## 小テストの書き方(quiz.ipynb)

`course.json` に `"quiz": "quiz.ipynb"` を書き、小テスト用のノートブックを用意します(必須)。
問題は、先頭に `<!-- @question ... -->` の設定ブロックを置いた Markdown セルで書きます。
このブロックは HTML コメントなので、Jupyter 上では表示されません。設定ブロックの無い Markdown セル(小テストの説明など)は読み飛ばします。

| 設定 | 内容 |
|---|---|
| `type` | `choice`(選択式)/ `numeric`(数値入力)/ `matrix`(表形式の選択)/ `code`(コード) |
| `answer` | 正解。選択式は選択肢の文言そのもの、数値入力は数値、表形式は行の順に正解の選択肢をカンマ区切り |
| `tolerance` | 数値入力の許容誤差(既定 `1e-6`) |
| `unit` | 関連する単元の番号(不正解のとき「復習」リンクを出す) |
| `explanation` | 正解したときに表示する解説 |

**選択式**:本文の最後の箇条書きが選択肢になります。

```markdown
<!-- @question
type: choice
answer: 中央値
unit: 3
explanation: 中央値は並べたときの真ん中の値なので、極端な値の影響を受けにくい。
-->
外れ値の影響を最も受けにくい代表値はどれですか。

- 平均
- 中央値
- 最大値
- 範囲
```

**数値入力**:

```markdown
<!-- @question
type: numeric
answer: 5
unit: 3
-->
データ `[2, 4, 4, 5, 10]` の平均を答えてください。
```

**表形式の選択**:本文の最後に Markdown の表を書きます(単元の「選択式・数値入力・表形式の演習」を参照)。

**コード**:問題セル(`type: code`)の直後に、演習と同じ `# @starter` / `# @solution`(/ `# @test`)セルを置きます。

受験できるのは講座の全単元を完了した後で、満点で講座修了です(何度でも受け直せます)。
各講座 10 問程度を目安に、単元の内容に合わせて最も適した形式を選んでください。

### 注意

- **単元には演習が1問以上必要です**(単元は、演習をすべて正解したときに完了になります)。
- 初期コードに `____` があると、Jupyter で「すべて実行」したときにそこで止まります。解答セルは個別に実行してから保存してください。
- 受講者の環境はブラウザ内の Python(Pyodide 314 / Python 3.14 / pandas 3.0)です。
  想定出力は、同じバージョンの pandas で作ると表示形式のずれが起きません。
- matplotlib の図は画像として表示されます。日本語フォントは入っていないため、軸ラベルなどは英語にしてください。
