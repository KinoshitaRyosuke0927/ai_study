KPT分析

Mattermost / Trello / GitHub / 変更履歴 / 実装差分 の分析結果をプロジェクト全体で束ね、KPT法(Keep / Problem / Try)で振り返った結果です。分析の実行は「定期実行設定」画面から行ってください。カードは列内での並び替え・別の列への移動ができ、右上の★で重要度(0〜5)を設定できます。「保存」で現在の状態を DB に保存します。

即時実行

各種ツールの情報取得・分析を一括で流します。フェーズ1(設計書 / コード / Mattermost / Trello / GitHub / 変更履歴)を並列実行したあと、フェーズ2(実装差分解析 / アクティビティ分析)を並列実行します。一部のステップが失敗しても後続は実行され、各ステップの成否が下のフロー図に表示されます。
