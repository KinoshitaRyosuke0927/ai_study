# 自動リマインドサービス

## できること

### 1. 対応が必要な投稿を見つけて、自動でリマインドする

監視対象のMattermostのチャンネル・GROUP SESSIONの掲示板を平日の営業時間中に5分ごとに確認します。対応が必要そうな投稿を見つけると、内容を要約して、指定したチームのチャンネルに次のような投稿をします。

```
@channel
#### 年末調整実施について
年末調整の実施の依頼が来ております。
経管への提出書類がある場合は、原本の提出も含めて期限までに対応が必要になりますので注意してください。
作業完了しましたら、 :sumi: スタンプを押してください。

**期日：11/20(金)**

(元の投稿のURL)
```

- 各自の作業がある **依頼** には、注意点・期日・完了スタンプの案内を付けます
- 障害や工事の案内のような **お知らせ** には、表題と元の投稿へのリンクだけを付けます
- 夜間や休日に届いた連絡は、次の営業日の朝9時にまとめてリマインドします

### 2. 期日が近づいたら、まだの人にだけ再リマインドする

期日のある依頼は、期日の3営業日前に、リマインド投稿に :sumi: スタンプを押していない人へ、スレッドの返信でもう一度お知らせします。

```
@user-a @user-b
リマインドした依頼の期日が近づいております。
作業完了しましたら、上のリマインド投稿に :sumi: スタンプを押してください。

**期日：11/20(金)**
```

- 再リマインドは1回だけです。全員が対応済みなら何も投稿しません
- 対象者が4人以上のときは、個別のメンションではなく @channel にします
- 土日・祝日・年末年始の会社休日は営業日として数えません

### 3. 同じ内容を何度もリマインドしない

同じ依頼が再掲や催促で何度投稿されても、リマインドするのは最初の1回だけです。その代わり、次のように変化があった点だけを最初のリマインドのスレッドでお知らせします。

| 再掲された投稿の内容 | ツールの動き |
|---|---|
| ただの再掲・催促 | 何も投稿しない |
| 期日が変わった | 「期日が変更されました」と返信し、再リマインドの日も組み直す |
| 新しい注意事項が増えた(提出先・必要書類など) | 「補足の連絡が来ております。」と補足の内容を返信する |
| 障害の復旧・工事の中止などの続報 | 元のお知らせのリマインドのスレッドに続報として投稿する |

同じ内容かどうか判断に迷う場合は、リマインドする側に倒します。重複して届くことはあっても、取りこぼさないことを優先しています。

## 使う人がすること

使う人がすることは、作業が終わったら **最初のリマインド投稿** に :sumi: スタンプを押すことだけです。押していれば、期日前の再リマインドの対象から外れます。

## しくみ

```
監視対象のチャンネル・掲示板
        │ 5分ごとに新しい投稿を取得
        ▼
① 絞り込みモデル … リマインドが必要そうな投稿だけを選ぶ
        ▼
② 生成AI … 種類・表題・作業内容・注意点・期日を抜き出す
             最近のリマインドと同じ内容か・続報かも判定する
        ▼
③ プログラム … 定型の文面に当てはめて投稿する
        ▼
チームのチャンネル(リマインド・再リマインド・スレッド返信)
```

- **① 絞り込み**: 過去の投稿を学習させた軽量な機械学習モデル(TF-IDF + ロジスティック回帰)を使います。すべての投稿を生成AIに渡さないので、費用を抑えられます
- **② 要約と判定**: Azure OpenAI のモデル(gpt-6-luna)で、元の投稿から必要な項目だけを JSON で抜き出します。同じ内容かどうかの判定も同じ呼び出しで行うので、呼び出し回数は増えません
- **③ 文面の組み立て**: 生成AIには文面そのものを書かせません。定型文、期日の曜日、元の投稿の URL はプログラムで組み立てます。AI が曜日やリンクを間違えることがなく、毎回同じ形式で投稿されます
- **実行環境**: Azure Functions のタイマーで動きます。画面はなく、誰かの PC を起動しておく必要もありません。設定はすべて Azure のアプリケーション設定で管理し、パスワードなどは Key Vault に保管しています

## 監視対象とリマインドの投稿先

### 監視対象

| サービス | チャンネル・掲示板 |
|---|---|
| Mattermost | JBD社員全体のお知らせ |
| Mattermost | JBD全体のお知らせ |
| Mattermost | 全員/拠点などの特定のお知らせ |
| Mattermost | 社員/拠点などの特定のお知らせ |
| Mattermost | 東京本社共有 |
| GROUP SESSION | 全社連絡用 |
| GROUP SESSION | 関東全体の情報共有 |

### リマインドの投稿先

| サービス | チャンネル |
|---|---|
| Mattermost | AIビジネス連絡事項 |

リマインド・期日前の再リマインド・スレッドへの返信は、すべて投稿先のチャンネルに投稿されます。再リマインドの対象者は、投稿先のチャンネルに参加しているメンバーです。
